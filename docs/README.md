These documents preserve context for contributors. Add or expand documentation
only with explicit user permission, and keep it concise enough to justify its
context cost.

`docs/doxygen/` is the Doxygen developer guide for human readers, built
locally; agents doing matching work need not read it.

There is deliberately no lessons.md and the commit hook rejects one. A codegen
finding belongs in the commit message of the body that proved it.
