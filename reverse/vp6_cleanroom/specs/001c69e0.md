Behaviour:
Builds a Huffman tree from per-symbol weights and writes it as an array of internal nodes.
Edge encoding: an edge dword with bit 0 set is a leaf whose symbol is in bits 1..7 (0x001C6A10..0x001C6A1D), an edge with bit 0 clear refers to the internal node whose index is in bits 1..7 (0x001C6B11..0x001C6B14).
Weights: any symbol weight of 0 is replaced by 1 in the caller's array before use (0x001C6A22..0x001C6A28).
Capacity: the scratch holds 64 records in total, symbols plus internal nodes (one less than the symbol count), so the symbol count must be at most 32, retail callers use 12 and 9.
Construction: symbols are ordered by ascending weight, where weights tie, a later-inserted record is placed before records of equal weight (comparison at 0x001C6A7A stops at an equal or larger weight). Repeatedly the two records of smallest weight are combined: a new internal node receives the lighter record's edge as its left edge and the second record's edge as its right edge, and its probability byte is the integer part of 256 times the first weight divided by the sum of the two weights (signed division at 0x001C6B0A, low byte stored at 0x001C6B1F). The combined record (weight = sum, edge = that node) is inserted into the remaining ordered records with the same before-equals rule (0x001C6B40..0x001C6B4A). Internal nodes are numbered downward: the first combination produces node (symbol count minus 2) (pointer decremented before the first stores, 0x001C6AF9) and the last combination, which joins the final two records, produces node 0, which is therefore the root. The last internal node written is also the one whose edges the readers start from.
