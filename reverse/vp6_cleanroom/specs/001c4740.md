Behaviour:
Installs the MMX transpose table address into field 0x13C (0x001C4744) and fills the 64-byte quant index so that it inverts the composition of the two tables: for every scan position (0..63) the MMX zig-zag entry is looked up, that value is looked up in the MMX transpose table, and the quant-index byte at the resulting position is set to the scan position (0x001C4751..0x001C475F, four positions per loop iteration). Afterwards the quant index maps an MMX-ordered coefficient slot back to its scan position.
