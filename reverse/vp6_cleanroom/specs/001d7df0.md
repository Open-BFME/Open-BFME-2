## Behaviour

SSE2 sub-pixel prediction block builder with the same argument contract as 0x001D7330 (installed in slot 0x00E22D1C for the SSE2 path). The difference B minus A is formed, exchanging the pointers and negating when it is negative (0x001D7DFF-0x001D7E09), a zero difference returns without writing (0x001D7E0D).

Bicubic selector non-zero (0x001D7E13-0x001D7F03): one of the 4-tap filters fills the 256-byte stack buffer with an 8x8 byte block, using weights at 0x00DB85E0 plus the phase times 64 (0x001D7E27-0x001D7E2D and corresponding sites): difference 1 selects the horizontal filter of A (args A, buffer, pixels per line, 1, 8, 8, horizontal-phase weights), difference equal to pixels per line selects the vertical filter (A, buffer, pixels per line, pixels per line, 8, 8, vertical-phase weights), pixels per line minus 1 selects the 2-D filter of A minus 1 and pixels per line plus 1 the 2-D filter of A (A or A - 1, buffer, pixels per line, horizontal-phase weights, vertical-phase weights), any other difference leaves the buffer unfilled. The buffer is then widened in-line to int16 into the output: eight rows, each read with an unaligned 16-byte load, the low eight bytes zero-extended and stored with an unaligned 16-byte store, output rows 16 bytes apart (0x001D7ECC-0x001D7EFC).

Bicubic selector zero (0x001D7F04-0x001D7FC0): the output is written directly by the int16-producing 2-tap filters with weights at 0x00DB84E0 plus the phase times 32, and the function returns right after the call: difference 1 gives 0x001D7BC0 with (A, output, pixels per line, 1, 8, 16, horizontal-phase weights), difference equal to pixels per line gives 0x001D7C20 with (A, output, pixels per line, pixels per line, 8, 16, vertical-phase weights), pixels per line minus 1 gives 0x001D7B00 with (A - 1, output, pixels per line, horizontal-phase weights, vertical-phase weights), pixels per line plus 1 gives the same with A, any other difference writes nothing.

No MMX state is used, esi (and edi on the bicubic path) are preserved.
