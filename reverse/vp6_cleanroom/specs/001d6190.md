## Behaviour

Generic (non-SIMD) dequantise plus inverse DCT. Calls 0x001D5DA0 with (quantiser matrix, input, local block) so the local block holds the 64 products as 32-bit values in natural raster order. First pass over the eight natural rows: a row whose eight entries are all zero is left as is, otherwise the 1-D transform is applied and the eight results are stored back into the row truncated to 16 bits. Second pass over the eight natural columns: a column whose eight entries are all zero produces eight zero outputs, otherwise the transform is applied with the rounding 8 and the arithmetic shift right 4, and each result is stored as int16 at output index 8 x row + column.

Arithmetic of this scalar routine (its own instruction sites are cited): the first pass works on the 32-bit dequantised products delivered by the helper (quantised value times quantiser entry as a signed 32-bit product), not on 16-bit coefficients. Every multiplication by a transform constant is a signed 32-bit multiply whose LOW 32 bits are kept and then arithmetically shifted right by 16 (0x001D6206-0x001D622D), written below as M32[c](v): it equals floor(v x c / 65536) only while the full product fits in 32 bits, i.e. while the magnitude of v is below about 33411 for the constant 64277 (proportionally larger bounds for the smaller constants), beyond that the product wraps modulo 2^32 before the shift. Sums and differences are 32-bit (they cannot overflow for inputs in that domain). Each first-pass result is stored truncated to its low 16 bits (16 word stores in the body) and sign-extended when the second pass reads it (0x001D631C and following). The second-pass rounding is 8 added before the final arithmetic shift right 4. The value contract is therefore the one given for 0x001D35E0 with every sat() and wrap() read as 32-bit arithmetic, every M[c] read as M32[c], and the first-pass outputs reduced modulo 65536 to the signed 16-bit range.

Check vectors: the DC, (0,1), (1,0) and five-coefficient vectors listed for 0x001D35E0 apply unchanged (no boundary is reached, quantiser entries 1). Discriminating case for the 32-bit multiply: coefficient 30000 at natural (0,1), quantiser entries all 2, everything else zero (dequantised value 60000, whose product with 64277 exceeds 2^31): every output row is -296, 157, -575, 517, -517, 575, -157, 296, whereas an exact-arithmetic multiplier would give -296, -692, -1423, 517, -517, 1423, 692, 296. The saturation vectors of the SIMD routines do not apply.
