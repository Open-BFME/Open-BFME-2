# Var16Point

name: Var16Point
rva: 0x001D8A30
size: 130
ret_site: 0x001D8AB1
convention: cdecl, 2 stack args, caller cleans
args: block pointer (bytes) | stride (int)
returns: uint32 variance metric
callees: none
tables: none
fields: none

## Behaviour

Population-variance style mismatch metric over 16 samples of an 8x8 block: for rows 0, 2, 4, 6 (stepping 2 x stride) take the pixels at columns 0, 2, 4, 6, accumulate their sum S and sum of squares Q. Returns ((Q shifted left 4) - S x S) shifted right 8 (unsigned 32-bit arithmetic).
