# MmxFastDeInterlace

name: MmxFastDeInterlace
rva: 0x001CDF60
size: 232
ret_site: 0x001CE047
convention: cdecl, 5 stack args, caller cleans
args: source (byte pointer) | destination (byte pointer) | width (int) | height (int) | stride (int)
returns: none
callees: none (row copies are inlined rep movs)
tables: 0x00DB7FD0: four 16-bit 2s (rounding)
fields: none

## Behaviour

SIMD variant of the vertical 1-2-1 deinterlace at 0x001C7580 with identical results: first row copied, each interior row written as (row above + 2 x row + row below + 2) shifted right by 2 per pixel computed in 16-bit lanes and packed back to bytes, last row copied. Processes 8 pixels per step, the column counter advances by 8 while below the width, so a width that is not a multiple of 8 is rounded up for the interior rows (the copies use the exact width). Source/destination advance by the stride. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
