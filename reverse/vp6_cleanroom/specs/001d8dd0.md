# VP6_PredictFiltered

name: VP6_PredictFiltered
rva: 0x001D8DD0
size: 170
ret_site: 0x001D8E79
convention: cdecl, 4 stack args, caller cleans
args: decoder instance pointer | reference block pointer (bytes, already offset to the current block) | motion x (int) | motion y (int)
returns: none
callees: via global pointers: 0x00E22D08 (12x12 copy: src, dst, src stride, dst stride)  | 0x00E22FA8 (loop filter across a vertical edge, 12 lines: q index, pointer, pitch) | 0x00E22FB4 (loop filter across a horizontal edge, 12 lines: q index, pointer, pitch)
tables: none
fields: +0x74 current reconstruction stride | +0x7C motion vector shift | +0x88 frame reconstruction stride | +0x13C quantiser pointer (its first uint32 is the frame q index) | +0x290 pointer to the 16-stride loop-filtered scratch block

## Behaviour

Builds the loop-filtered 12x12 prediction neighbourhood for a block.

1. Each motion component is reduced to whole pixels by an arithmetic shift right by the shift count at +0x7C, rounding toward zero (a negative component is negated, shifted, and negated back, 0x001D8DE5-0x001D8E03).
2. The source address is the reference pointer displaced by the whole-pixel vertical offset times the frame stride (+0x88) and by the whole-pixel horizontal offset, then moved up two rows of the current stride (+0x74) and left two columns.
3. The 12x12 region at that address (row stride +0x74) is copied into the scratch block at +0x290 (row stride 16) through the function pointer at 0x00E22D08 with arguments (source, scratch, +0x74, 16).
4. A horizontal boundary offset is derived from the whole-pixel horizontal offset as its negation masked to 0..7, and a vertical one likewise from the vertical offset (0x001D8E2A-0x001D8E34).
5. If the horizontal boundary offset is non-zero, the vertical-edge loop filter at 0x00E22FA8 is called with (frame q index, scratch + 2 + that offset, 16). If the vertical boundary offset is non-zero, the horizontal-edge loop filter at 0x00E22FB4 is called with (frame q index, scratch + 16 x (2 + that offset), 16).

This retail version takes no block-position argument, it uses the single shift/stride fields listed above.
