name: vp6_xprintf
rva: 0x001C4C90
size: 610
ret_site: 0x001C4EF1
convention: cdecl, variadic
args: [esp+4] pointer to the decoder instance, [esp+8] pixel offset into the post-process buffer, [esp+0xC] format string, then the format arguments
returns: int, length of the formatted text (0 on any GDI failure)
callees: _vsnprintf (IAT 0x00BBA5E0), CreateCompatibleDC (0x00BBA0E0), CreateBitmap (0x00BBA0B0), SelectObject (0x00BBA0D8), CreateFontA (0x00BBA0A8), SetTextColor (0x00BBA0A0), SetBkColor (0x00BBA09C), SetBkMode (0x00BBA0B4), BitBlt (0x00BBA0C8), ExtTextOutA (0x00BBA094), GetPixel (0x00BBA080), DeleteObject (0x00BBA0C0), DeleteDC (0x00BBA0DC)
tables: none
fields: 0x1B8 Y stride (decoder configuration), 0x25C post-process buffer

Behaviour:
Renders text into the luma plane for debugging. Formats into a 256-byte buffer. Creates a memory DC and a 1-bit bitmap of width 8 times the text length and height 8, selects it, creates an 8-pixel variable-pitch sans font and selects it, sets text colour 1, background 0 and transparent mode, clears the bitmap with a BLACKNESS blit, draws the text clipped to the rectangle. Then for each of the 8 rows and each column, if GetPixel at (x, 7 minus y) is non-zero the byte at post-process buffer plus offset plus y times Y stride plus x is set to 255. Cleans up the GDI objects and returns the text length. Any failure along the way skips to the cleanup and returns 0.
