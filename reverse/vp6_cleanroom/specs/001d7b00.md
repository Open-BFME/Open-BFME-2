# FilterUnpackBlock2dBil_wmt

name: FilterUnpackBlock2dBil_wmt
rva: 0x001D7B00
size: 188
ret_site: 0x001D7BBB
convention: cdecl, 5 stack args, caller cleans
args: source pointer (bytes) | output pointer (int16, 64 entries pitch 8) | source pixels per line (uint) | horizontal taps (int16 pointer) | vertical taps (int16 pointer)
returns: none
callees: none
tables: 0x00DB84D0 eight 16-bit 64 (rounding)
fields: none

## Behaviour

Same two-pass bilinear 2-D filter as 0x001D7A40 (horizontal pass over nine rows, each sample and its right neighbour weighted by the two eight-entry weight groups of the horizontal taps pointer, 64 added, shift right 7, rounded to 8-bit precision, then vertical pass between consecutive filtered rows with the vertical weight groups, 64 added, shift right 7), except that the final 8x8 result is stored as int16 values (one 16-byte row store per output row, pitch 8 entries) instead of bytes. Values are within 0..255.
