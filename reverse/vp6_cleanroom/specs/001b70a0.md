name: VP6_init_dequantizer
rva: 0x001B70A0
size: 277
ret_site: 0x001B71B4
convention: cdecl
args: [esp+4] pointer to QUANTIZER (retail quantizer instance, 0x990 bytes) (version argument unused)
returns: void
callees: none
tables: 0x00BD7860 Y AC threshold (low 16 bits used), 0x00BD7E60 Y DC quantizer (short), 0x00BD7960 UV AC threshold, 0x00BD7EE0 UV DC quantizer
fields: 0x0 frame Q index, 0x140 quant index bytes, 0x180 Y dequantiser pointer (64 shorts), 0x184 UV dequantiser pointer

Behaviour:
Let q be the frame Q index. For positions i from 1 to 63 (unrolled three at a time): the Y dequantiser short at index quantIndex[i] is set to the Y AC threshold entry for q, shifted left 2. The Y dequantiser short at index 0 is set to the Y DC quantizer entry for q shifted left 2. The same is done for the UV dequantiser with the UV tables. Values are truncated to 16 bits.
