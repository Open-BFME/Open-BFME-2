# HorizontalLine_1_2_Scale_MMX

name: HorizontalLine_1_2_Scale_MMX
rva: 0x001D2700
size: 193
ret_site: 0x001D27C0
convention: cdecl, 4 stack args, caller cleans (ebp frame)
args: source line (bytes) | source width (uint) | destination line (bytes) | destination width (unused)
returns: none
callees: none
tables: 0x00BD9960 four 16-bit 1 (rounding)
fields: none

## Behaviour

Horizontal 1-to-2 upscale of one line: every source pixel is copied to the even destination position twice its index, and the odd destination position after it receives the rounded-up average of that source pixel and its right neighbour (sum plus 1, shifted right 1). The last source pixel has no right neighbour: both of its destination positions receive its own value. The MMX body interleaves eight source bytes with eight averages per step (16 destination bytes) and handles the line tail so that the last-pixel rule holds. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
