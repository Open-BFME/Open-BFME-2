# SubtractBlock_MMX

name: SubtractBlock_MMX
rva: 0x001D7780
size: 66
ret_site: 0x001D77C1
convention: cdecl, 3 stack args, caller cleans
args: source (bytes) | target (int16 pointer, pitch 8, modified in place) | line step (uint)
returns: none
callees: none
tables: none
fields: none

## Behaviour

For 8 rows of 8: target = source byte (zero-extended) - target, as int16 wrapping arithmetic. Source rows advance by the line step, target rows by 8 entries. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
