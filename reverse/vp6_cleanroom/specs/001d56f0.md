# ScalarReconIntra

name: ScalarReconIntra
rva: 0x001D56F0
size: 153
ret_site: 0x001D5788
convention: cdecl, 4 stack args, caller cleans
args: int16 scratch block (64 entries) | output (byte pointer) | residual (int16 pointer, 64 entries, stride 8) | line step (uint)
returns: none
callees: 0x001D55C0 SatUnsigned8
tables: none
fields: none

## Behaviour

Intra reconstruction without SIMD: each of the 64 residual values plus 128 is stored into the scratch block (as int16, wrapping), then the scratch block is written to the output through SatUnsigned8 with (output, scratch, line step, 8).
