## Behaviour

Weak de-ringing filter for one 8x8 block (SSE2 blend with MMX weight construction). Inputs: the strength value is the quantiser-scale table entry for the block's quality index (sixth and fifth arguments), and the sharpening value is the entry for the same quality index of the 64-entry int32 table at 0x00DB7A28 (values -12, -11, -10, -10, -9, -9, -9, -9, eight -6, eight -4, sixteen -2, twenty-four 0). The upper cap on a neighbour weight is the smaller of three times the strength value and 24 (the cap is realised with the byte constant 255 - 24 = 231 listed in the tables and saturating byte adds/subtracts), the lower cap is 0.

Neighbour weights: a 'vertical' weight is computed for each of the nine horizontal pixel boundaries of every column (between the row above the block and row 0, between successive rows, and between row 7 and the row below), and a 'horizontal' weight for each of the nine vertical boundaries of every row (one pixel left and one right of the block are read). A weight starts as 32 plus the strength value minus twice the absolute difference of the two pixels across the boundary, if that is below -64 it is replaced by the sharpening value, otherwise it is clamped to the range 0..cap. The weights are built in 16-bit lanes and stored in two stack tables.

Output: every destination pixel is a weighted blend of the source pixel with its four neighbours: each neighbour contributes its boundary weight times its value, the centre contributes (128 minus the four weights) times its value, 64 is added (16-bit 64s constant listed) and the total is shifted right 7 (logical shift on 16-bit lanes, 0x001D3203), then packed to bytes with unsigned saturation. Only the 8x8 block is written, the destination uses the same pitch as the source.

Row visibility and aliasing: both weight tables are completely built from the original neighbourhood before any output store. The output is then produced row by row, and each row's blend re-reads the pixel rows above, at and below it from the source pointer at that moment (per-row loads at 0x001D315A, 0x001D316B, 0x001D317D, 0x001D318E, 0x001D31BB, row store 0x001D320C, loop back 0x001D3211). When the destination aliases the source (in-place filtering) the row above the current row has already been replaced by its filtered value when it is read as the upper neighbour, so results differ from a disjoint-buffer call. Check case (retail-emulated): pitch 32, a neighbourhood of 100 everywhere, a single 108 at block-relative (3,3), quality index 0, scale table entries all 10: with disjoint buffers pixel (4,3) becomes 102, with destination equal to source it becomes 100. Callers that need disjoint-buffer results must not alias the two pointers.

Processor state: despite the SSE2 name the routine executes MMX instructions while building the weight tables (e.g. 0x001D2F97, 0x001D2FDC) and transfers them to XMM registers (0x001D3025), the blend itself uses SSE2. No emms is executed anywhere in the routine, so the MMX register state is left in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
