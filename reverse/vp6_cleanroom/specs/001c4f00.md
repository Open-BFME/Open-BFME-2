name: VP6_DecodeBool
rva: 0x001C4F00
size: 114
ret_site: 0x001C4F71
convention: cdecl
args: [esp+4] pointer to the bool coder state (0x0 low value, 0x4 range, 0x8 value window, 0xC count, 0x10 byte position, 0x14 buffer pointer), [esp+8] probability of a 0 symbol scaled to 0..255
returns: decoded bit (0 or 1)
callees: none
tables: none
fields: bool coder 0x4 range, 0x8 value window, 0xC count, 0x10 byte position, 0x14 buffer

Behaviour:
Decodes one binary symbol whose probability of being 0 is the second argument over 256. The decoder state is a range and a 32-bit value window compared through its top byte. On entry the range lies in 128..256 (the equiprobable helpers VP6_DecodeBool128 can leave it at exactly 256), and on exit it lies in 128..255. The boundary for the symbol is 1 plus the product of (range minus 1) and the probability divided by 256 (0x001C4F08..0x001C4F1D). The symbol is 1 when the window's value is at least the boundary placed in the top byte (0x001C4F21..0x001C4F26), the window and range then both lose the boundary amount, otherwise the range becomes the boundary. The range is then renormalised by doubling while it is below 128 (tests at 0x001C4F33 and 0x001C4F5C, so no doubling happens when the selected range is already 128 or more), the window being doubled in step, every doubling consumes one bit, decrementing the refill count, and when the count reaches 0 the next unread buffer byte (at the byte position, which advances) is merged into the low byte of the window and the count resets to 8 (0x001C4F40..0x001C4F62). Range, window, count and position are written back.
