name: FilterBlock1d
rva: 0x001B8050

convention: cdecl
args: [esp+4] source pointer, [esp+8] output pointer, [esp+0xC] source pixels per line, [esp+0x10] pixel step, [esp+0x14] output height, [esp+0x18] output width, [esp+0x1C] pointer to the filter taps
returns: void (16-bit outputs)
callees: none
tables: none
fields: none

Behaviour:
Four-tap filter producing 16-bit samples: for each of output-height rows and output-width columns, output = (tap0 times the sample one step before plus tap1 times the sample plus tap2 times the sample one step after plus tap3 times the sample two steps after plus 64) shifted right 7 (arithmetic), clamped to 0..255. The source pointer advances one byte per column and then by (pixels per line minus output width) per row, the output advances by output width entries per row. Nothing happens when the height is 0.
