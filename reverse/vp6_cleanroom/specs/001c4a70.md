name: VP6_quantize_mmx
rva: 0x001C4A70
size: 539
ret_site: 0x001C4C8A
convention: cdecl (stack realigned to 16 bytes internally)
args: [esp+4] pointer to the quantizer instance, [esp+8] pointer to 64 signed-16 DCT coefficients, [esp+0xC] pointer to 64 signed-16 output, [esp+0x10] block position byte
returns: void
callees: none
tables: 0x00BD8760 plane selector (6 bytes 0,0,0,0,1,1), 0x00DB7B28 zig-zag order (64 dwords, same values as 0x00BD8460)
fields: 0x8 eight 16-bit rounding values, 0x18 eight 16-bit multipliers, 0x190 quantizer multipliers [plane][64], 0x390 rounding [plane][64], 0x590 zero-bin [plane][64], 0x790 zero-run corrections [plane][64]

Behaviour:
Forward quantization of one block in scan order with dead-zone rounding, using a vector pre-pass. The plane row of the constant tables is chosen by the block position through the selector. Vector stage: for all 64 coefficients, in groups, the magnitude of each coefficient is increased by the 16-bit rounding value, multiplied by the 16-bit multiplier keeping the high 16 bits of the unsigned product, and given back the coefficient's sign, these candidates are kept in a 64-entry local array while the output block is zeroed (MMX loop, four coefficients per step).
DC: a coefficient at or above the plane's DC zero-bin size is increased by the DC rounding value, multiplied by the DC multiplier and the high 16 bits kept, at or below the negative zero-bin it is decreased by the rounding value, multiplied, 0xFFFF added and the high 16 bits kept, otherwise it stays zero and the zero run starts at 1.
AC: scan positions 1..63 in order, each mapping to a raster position through the zig-zag table (three per loop iteration). When the candidate for that raster position is zero, the run grows. Otherwise, when the coefficient's magnitude is below the plane's zero-bin size for that raster position plus the zero-run correction for the current run length, the run grows. Otherwise the candidate is stored at the scan position and the run resets to 0.
This variant matches VP6_quantize_wmt except for the vector width.
