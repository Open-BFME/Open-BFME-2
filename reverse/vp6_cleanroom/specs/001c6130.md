convention: cdecl
args: [esp+4] pointer to PB_INSTANCE (retail decoder instance), [esp+8] block position

callees: 0x001C5E30 VP6_PredictFilteredBlock, pointers 0x00E22F64 (inter reconstruction: temp, destination, reference, coefficients, stride), 0x00E22F68 (block reconstruction: temp, coefficients, destination, stride), 0x00E22F6C (intra reconstruction: temp, destination, coefficients, stride)
tables: 0x00DB7040 modes using motion compensation (10 dwords: 0,0,1,1,1,0,1,1,1,1)
fields: 0x8 mode, 0x70 reconstruction index, 0x74 current stride, 0x284 temporary data buffer, 0x270 reconstruction coefficient buffer, 0x244 this-frame recon, 0x254 last-frame recon, 0x24C golden frame

Behaviour:
Mode 0: inter reconstruction with destination = this frame plus the reconstruction index and reference = last frame plus the same index. Modes flagged in the table: predicts the filtered block into the temporary buffer then block-reconstructs it into this frame. Mode 5: inter reconstruction from the golden frame. Any other mode: intra reconstruction into this frame.
