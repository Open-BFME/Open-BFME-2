# UnpackBlock_MMX

name: UnpackBlock_MMX
rva: 0x001D7740
size: 53
ret_site: 0x001D7774
convention: cdecl, 3 stack args, caller cleans
args: source (bytes) | output (int16 pointer, pitch 8) | pixels per line (uint)
returns: none
callees: none
tables: none
fields: none

## Behaviour

Widens an 8x8 byte block to int16 (zero extension): 8 rows, source rows pixels-per-line apart, output rows 8 entries apart. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
