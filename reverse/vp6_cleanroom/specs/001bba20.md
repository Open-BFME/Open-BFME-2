name: BuildScanOrder
rva: 0x001BBA20
size: 200
ret_site: 0x001BBAE7
convention: cdecl
args: [esp+4] pointer to PB_INSTANCE (retail decoder instance), [esp+8] pointer to 64 scan-band bytes
returns: void
callees: none
tables: none
fields: 0x5BC modified scan order (64 bytes), 0x5FC end-of-block offset table (64 bytes), 0x19C version byte

Behaviour:
Entry 0 of the modified scan order is 0. Then for band 0 through 15 and coefficient position j from 1 to 63, every position whose scan-band byte equals the band is appended to the modified scan order in increasing j. Then for each i from 0 to 63, the end-of-block offset entry i is the largest modified-scan-order value among entries 0..i, plus 1 when the version byte exceeds 6. (Retail unrolls the second loop four entries at a time.)
