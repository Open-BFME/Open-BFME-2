convention: cdecl, 3 stack args, caller cleans
args: input (int16 pointer) | quantiser table (int16 pointer) | output (int16 pointer, 64 entries, 16-byte aligned)
returns: none
callees: none

fields: none

## Behaviour

DC-only inverse transform, SSE2: loads the first four input and table entries, multiplies lane-wise (only lane 0 matters), adds 15, arithmetic-shifts right 5, broadcasts lane 0 to all 8 lanes and stores the 16-byte vector 8 times (64 identical outputs). Unlike 0x001D45F0 there is no zero special case (a zero DC simply yields zeros). Installed for the SSE2 path for 0..1 coefficient blocks in both pointer tables.
