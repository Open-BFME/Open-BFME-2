# FilterBlock2d_wmt

name: FilterBlock2d_wmt
rva: 0x001D7D90
size: 83
ret_site: 0x001D7DE2
convention: cdecl, 5 stack args, caller cleans (256-byte local buffer)
args: source pointer (bytes) | output pointer (bytes, 8x8 pitch 8) | source pixels per line (uint) | horizontal taps (int16 pointer) | vertical taps (int16 pointer)
returns: none
callees: 0x001D7820 FilterBlock1d_h_wmt | 0x001D78C0 FilterBlock1d_v_wmt
tables: none
fields: none

## Behaviour

SSE2 twin of 0x001D72D0: horizontal 4-tap filter of 11 rows starting one line above the source into a 256-byte buffer (pitch 8), then vertical 4-tap filter from buffer row 1 producing the 8x8 output.
