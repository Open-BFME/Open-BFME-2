# FilterVert_Simple_MMX

name: FilterVert_Simple_MMX
rva: 0x001D2A70
size: 424
ret_site: 0x001D2C17
convention: cdecl, 4 stack args, caller cleans (ebp frame)
args: postproc instance pointer | pixel pointer (bytes, at the second-side inner pixel of line 0, i.e. the first row below the edge) | pitch (int) | bounding pointer (unused)
returns: none
callees: none
tables: 0x00BD99C0 eight bytes 0xFF | 0x00BD99D0 four 16-bit 4 | 0x00BD99E0 four 16-bit 1 | 0x00BD9A00 eight bytes of 1 | 0x00BD9A10 eight bytes of 128 | 0x00E22CEC deblock limit table pointer
fields: +0xC frame q index

## Behaviour

Simple-profile deblocking filter across one block edge, 8 lines, MMX. The limit is entry [frame q index] (field +0xC) of the uint32 table whose pointer is stored at 0x00E22CEC, the fourth argument is ignored. Each line has four contributing pixels, two on each side of the edge (horizontal edge: the four pixels of a line are at row offsets -2 x pitch, -pitch, 0 and +pitch, lines are the eight columns, processed as 8 byte lanes at once).

High-difference flag (byte domain, computed before any widening): the outer and inner pixel of the first side are subtracted as bytes with wrap-around (0x001D2AB2), and likewise the inner and outer pixel of the second side (0x001D2ACC), each wrapped signed-byte difference is compared with the signed-byte constants -1 (eight bytes 0xFF at 0x00BD99C0) and 1 (eight bytes of 1 at 0x00BD9A00), the flag is set for a line when either difference is greater than 1 or less than -1 as a signed byte (0x001D2AB5-0x001D2ADF). Because the difference wraps, neighbours 0 and 255 give a difference of 1 or -1 and do NOT set the flag, unlike a true absolute-difference test, 0 and 254 do set it.

Correction: three times the difference between the second-side inner pixel and the first-side inner pixel, computed in 16-bit lanes, when the flag is set the difference between the first-side outer pixel and the second-side outer pixel is added (masked by the flag). Then 4 is added (0x00BD99D0, 0x001D2B44) and the value is arithmetically shifted right 3 (0x001D2B55), it is bounded with the limit (sign mask from the ones at 0x00BD99E0, 0x001D2B80, magnitude kept below the limit, folded back between the limit and twice the limit, zero beyond, sign preserved). The first-side inner pixel is increased and the second-side inner pixel decreased by the bounded correction. For lines whose flag is clear, half the correction (arithmetic shift right 1, 0x001D2BE2) is also added to the first-side outer pixel and subtracted from the second-side outer pixel. Results are clamped to 0..255 (the deltas are applied to 0x80-biased bytes with saturating byte arithmetic, bias constant at 0x00BD9A10). The four affected rows are written back as 8-byte stores. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
