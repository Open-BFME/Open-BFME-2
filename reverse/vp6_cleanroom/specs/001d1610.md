# FillLoopFilterLimitValues_MMX

name: FillLoopFilterLimitValues_MMX
rva: 0x001D1610
size: 57
ret_site: 0x001D1648
convention: cdecl, no args
args: none
returns: none
callees: none
tables: 0x00E22CE0: global pointer to the active 64-entry uint32 loop-filter limit table (indexed by q index) | 0x00E229E0: global 64 x 4 int16 array (512 bytes) filled by this routine
fields: none

## Behaviour

Expands the loop-filter limit table for SIMD use: for each q index i = 0..63 reads the uint32 limit at table[i] through the pointer stored at 0x00E22CE0 and writes its low 16 bits four times at 0x00E229E0 + 8i (entries 4i .. 4i+3). Called by the MMX/SSE machine configuration routine before the loop-filter function pointers are installed.
