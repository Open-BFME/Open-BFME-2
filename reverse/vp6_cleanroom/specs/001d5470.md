# CpuProbe_VendorSse2 (EA CPU feature probe)

name: CpuProbe_VendorSse2 (EA CPU feature probe)
rva: 0x001D5470
size: 208
ret_site: 0x001D553F
convention: cdecl, no args | SEH frame (handler record 0x00BD9A38, filter 0x001D5510, handler 0x001D5520)
args: none
returns: int: 1 if the processor is GenuineIntel or AuthenticAMD and reports SSE2, else 0
callees: import slot 0x00BBA55C (memcmp)
tables: 0x00BD9A28 'GenuineIntel' | 0x00BD9A18 'AuthenticAMD' (12-byte vendor strings)
fields: none

## Behaviour

Sets a result local to 0, executes CPUID leaf 0 and stores EBX, EDX, ECX (the 12-byte vendor string) into a local buffer. Compares the buffer with 'GenuineIntel' (12 bytes) and, if different, with 'AuthenticAMD', if neither matches the result stays 0. Otherwise executes CPUID leaf 1 and, if bit 26 of EDX (SSE2) is set, sets the result to 1. Returns the result. The whole body is wrapped in a structured exception frame: the filter at 0x001D5510 always selects the handler, and the handler at 0x001D5520 returns 0, so an invalid-opcode fault (no CPUID) yields 0. Called by the machine-configuration routine at 0x001C4396 to choose the SSE2 code paths.
