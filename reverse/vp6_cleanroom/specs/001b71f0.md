Prepares the forward-quantization constants for the current Q index, separately for the luma plane (plane 0 rows) and the chroma plane (plane 1 rows, from the UV tables).
Multipliers (field 0x190): each entry is the fixed-point reciprocal of four times a quantizer value, scaled by 65536 and rounded to nearest (0.5 added before truncation, double precision, conversion at 0x001B721F and 0x001B7281). For index 0 of a plane the quantizer value is the plane's DC quantizer entry (signed 16-bit), for indices 1..63 it is the plane's AC threshold entry (converted as an unsigned integer). The same reciprocal is therefore stored in all 63 AC entries of a plane.
Rounding values (field 0x390): index 0 of a plane holds the plane's DC rounding entry, indices 1..63 the plane's AC rounding entry.
Zero-bin sizes (field 0x590): index 0 holds the plane's DC zero-bin entry, indices 1..63 the plane's AC zero-bin entry.
SIMD vectors: the eight 16-bit rounding values (field 0x8) all hold the low 16 bits of the luma AC rounding value, the eight multipliers (0x18) the luma AC multiplier, and the eight zero-bin values (0x28) the luma AC zero-bin size minus 1 (0x001B735E..0x001B7452).
Zero-run corrections (field 0x790): for each run length index 0..63 and each plane, the entry is the plane's AC threshold entry times 4 times the correction percentage for that index, divided by 100 with truncation toward zero (signed division by the multiplier 0x51EB851F with shift 5 and sign fix, 0x001B7461..0x001B7482).
