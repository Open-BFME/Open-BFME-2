rva: 0x001CA000
size: 4240

fields: +0xC frame q index | +0x24 pointer to the per-block q index array (int32 per block) | +0x28 pointer to the per-block variance accumulator array (int32 per block)

## Behaviour

MMX band deblocker using an absolute-difference activity test and a single frame-level quantiser step. Setup: q is the scale-table entry for the frame quality index (field +0xC, multiplied by 4 at 0x001CA02A to address the table), replicated into 16-bit lanes and also packed to bytes, the deblock loop limit for the frame q index is read through 0x00E22CEC and replicated. The smoothing limit is formed in MMX at 0x001CA0C2-0x001CA0E2: q is added to itself twice (three times q), arithmetically shifted right 2, packed to bytes and biased by subtracting the 0x80 constant at 0x00DB7FC0 so that it can be compared against byte sums with signed compares.

Same interleaved order as 0x001C8A30 (horizontal edge above each block, then for every block but the first the vertical edge on its left, in place on the destination eight rows up). Per line of an edge (eight edge pixels plus one outer sample on each side):
- activity per side = the sum of the absolute differences between neighbouring samples along that side, including the step to the outer sample (four differences per side). Each side's activity, limited to 255, is added into the block's accumulator at +0x28 (the SIMD code keeps the per-line sums as bytes with saturation and adds the eight of them).
- the line is smoothed when both activities are below the smoothing limit and the absolute difference of the two pixels touching the edge is below q.
- smoothing: each of the eight edge pixels is replaced by the rounded mean of the seven-sample window centred on it with the centre counted twice (total weight 8: add the 16-bit 4s at 0x00DB7FA0, arithmetic shift right 3, e.g. 0x001CA2DD-0x001CA2EA), window samples beyond the first or last edge pixel take the value of the outer sample on that side (the outer samples are used directly, there is no 'closer than q' selection in this routine).

- a line that is not smoothed receives the four-tap loop filter instead: a correction equal to (first-side inner-but-one pixel minus three times the first-side edge pixel plus three times the second-side edge pixel minus the second-side inner-but-one pixel, plus 4) arithmetically shifted right 3, bounded with the deblock loop limit (the uint32 table whose pointer is stored at 0x00E22CEC, entry [frame q index]), the two pixels touching the edge are moved towards each other by that amount (added on the first side, subtracted on the second, clamped to 0..255) and the other six pixels of the line are copied unchanged.
Bounding rule used by the loop filters in this library (named 'bound' below): a correction value is kept unchanged while its magnitude is below the limit, is reduced linearly beyond that so that a magnitude of twice the limit maps to zero (the response is the limit minus the distance of the magnitude from the limit), and is zero for magnitudes of twice the limit or more, the sign of the original value is preserved. The SIMD code realises this with arithmetic shifts by 15 to extract signs, saturating subtractions and a multiply by a sign mask built from the replicated 16-bit ones.
