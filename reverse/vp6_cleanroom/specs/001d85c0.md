## Behaviour

Notation used below: inputs of a 1-D transform are in0..in7, its outputs out0..out7, intermediate terms are named by role, multiplier constants by their retail value (M[c](v) = floor(v x c / 65536), see the multiplier notation paragraph), sat() = clamp to -32768..32767, wrap() = modulo 65536.
Storage layout (SSE2 path): transmission coefficient i is stored at storage index entry i of the table at 0x00DB7E28. That table is the transpose of the ordinary zig-zag map (its first non-DC entry is 8, not 1), so the stored block is the natural block transposed: stored row r (16 bytes at offset 16r) holds natural column r, and lane j of a stored row holds natural row j. The quantiser table uses the same storage order. Input, quantiser and output are accessed with aligned 128-bit loads/stores (movdqa, in this routine 0x001D85D4-0x001D8608) and must therefore be 16-byte aligned.

Pass arrangement: the first pass combines the eight stored rows lane-wise (reduced input loads of stored rows 0..3 beginning 0x001D860D), since stored row r is natural column r, the frequency index of that pass runs across registers (natural column index) while each lane is one natural row - the first pass is therefore the transform of the eight NATURAL ROWS, done for all eight rows in parallel. One 8x8 16-bit register transpose follows (unpack sequences from 0x001D875B), after which stored row r holds natural row r, the second pass combines those registers lane-wise, i.e. transforms the eight natural columns in parallel, with the rounding constant (0x00DB8800 via paddsw at 0x001D8911, 0x001D894A, 0x001D8968, 0x001D8990) and the arithmetic shift right 4 (0x001D8921-0x001D89AA). The result is stored in natural raster order (row r at output byte offset 16r). Natural-row first, natural-column second, exactly one intervening transpose.

Reduced routine (SSE2 path, 2..10 coefficients): only stored rows 0..3 are loaded, dequantised (four lane-wise multiplies, aligned loads and multiplies 0x001D85D4-0x001D85F5) and written to the working block (aligned stores 0x001D85FA-0x001D8608), nothing is written to working rows 4..7 before the passes: those rows are first written by the first pass with its computed results (stores 0x001D8724 and 0x001D873A-0x001D8744), and the transform treats the frequencies that were not loaded as zero by construction of the reduced contract, not by zero-filling the buffer. In natural coordinates the first pass transforms all eight natural rows with inputs in0..in3 = natural columns 0..3 (columns 4..7 zero), natural rows 4..7 have all-zero inputs and yield zero. After the transpose, the second pass transforms all eight natural columns with inputs in0..in3 = natural rows 0..3 (rows 4..7 zero), with rounding and shift, writing the full raster block.

Value contract of the reduced 1-D transform (inputs in0..in3 only, in4..in7 are not read and are taken as zero), obtained by symbolic evaluation of this routine's instruction stream, multiplier and sat/wrap notation as in the full contract of 0x001D35E0:
- oddSum17 = M[64277](in1), oddDiff17 = M[12785](in1), oddSum35 = M[54491](in3), oddDiff35 = sat(0 - M[36410](in3)) (a saturating negation).
- oddDS = sat(oddSum17 - oddSum35), oddSS = sat(sat(oddSum35 + oddSum35) + oddDS), oddDM = sat(oddDiff17 - oddDiff35), oddSM = sat(sat(oddDiff35 + oddDiff35) + oddDM), rotS = M[46341](oddDS), rotM = M[46341](oddDM) (wrapping add-backs).
- even term: rotEven = M[46341](in0) with wrapping add-back, it serves as both the even sum and the even difference (there is no separate saturating add-back in the reduced routines).
- pairSum26 = M[60547](in2), pairDiff26 = M[25080](in2).
- second stage: eA = sat(rotEven - pairSum26), eB = sat(sat(pairSum26 + pairSum26) + eA), oA = sat(rotM - pairDiff26), oB = sat(sat(pairDiff26 + pairDiff26) + oA), fA = sat(rotEven - rotS), fB = sat(sat(rotS + rotS) + fA).
- outputs exactly as in the full contract (first pass: out7 = sat(eB - oddSS), out0 = sat(sat(oddSS + oddSS) + out7), out2/out1 from fB and oB, out4/out3 from eA and oddSM, out6/out5 from fA and oA, second pass with the saturating +8 on each pair's difference and the arithmetic shift right 4 on both results).
The reduced MMX routines (0x001D3F30, 0x001D4D50) and the reduced SSE2 routine (0x001D85C0) evaluate identical value trees.
