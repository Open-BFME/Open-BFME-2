## Behaviour

Sets the cut-off field to 64 (0x001D8ACA) and fills the threshold table from its top end downwards. For the first cut-off entries counting down from index 255 (index 255, 254, ... down to 255 minus cut-off plus 1) the value stored is the unsigned integer quotient of (six times the cut-off minus five times the number of entries already written) by the cut-off (the cut-off is re-read from the field for every entry, 0x001D8AE0-0x001D8B03), i.e. a linear ramp from 6 down toward 1. The remaining entries down to index 1 are set to 1 (0x001D8B20). Index 0 is not written. Unreferenced in retail, the table is read by 0x001D8B40.
