# MMXReconIntra

name: MMXReconIntra
rva: 0x001D7520
size: 55
ret_site: 0x001D7556
convention: cdecl, 4 stack args, caller cleans
args: scratch (unused) | destination (bytes) | residual (int16 pointer, 64 entries, row pitch 16 bytes) | stride (uint)
returns: none
callees: none
tables: 0x00DB84C0 eight bytes of 0x80 (bias)
fields: none

## Behaviour

Intra reconstruction: for each of 8 rows, the eight residual words are packed to signed bytes with signed saturation (clamped to -128..127, 0x001D753D) and the packed bytes are exclusive-ored with 0x80 (0x001D7544), which maps -128..127 onto 0..255, the eight bytes are stored to the destination row (0x001D754C). The observable result per pixel is the residual plus 128 clamped to 0..255. Residual rows are 16 bytes apart, destination rows stride apart. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
