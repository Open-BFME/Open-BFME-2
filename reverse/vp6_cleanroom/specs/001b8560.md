Behaviour:
Motion-compensated sub-pixel prediction into a 16-bit block. Let d = pointer 2 minus pointer 1, swapping the pointers when negative so d is non-negative and pointer 1 is the lower address.
 d equal to 1 (horizontal half-step): bicubic flag set gives FilterBlock1d(pointer 1, output, pixels per line, step 1, 8, 8, bicubic row for the horizontal phase). Otherwise an inlined horizontal two-tap with the bilinear pair for the horizontal phase, 8 rows of 8, 16-bit output.
 d equal to pixels per line (vertical): bicubic gives FilterBlock1d with step = pixels per line and the bicubic row for the vertical phase, else the inlined vertical two-tap with the bilinear pair for the vertical phase.
 d equal to pixels per line minus 1 (diagonal, pointer 2 below-left): bicubic gives FilterBlock2d(pointer 1 minus 1, output, pixels per line, bicubic rows for the horizontal and vertical phases), else FilterBlock2dBil with the same base and the bilinear pairs.
 d equal to pixels per line plus 1 (below-right): the same two calls with base pointer 1.
 Any other d: no output is written.
