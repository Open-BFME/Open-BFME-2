Behaviour:
For each 6-bit prefix (0..63, the entry index): starting at node 0, prefix bits are consumed from the most significant one, taking the node's right edge for a 1 and its left edge for a 0 (0x001C6BC2..0x001C6BE1), until a leaf edge is reached or all 6 bits have been used. The 16-bit entry packs: bit 0 = the leaf flag of the final edge, bits 1..7 = its token or node index (the 7-bit value masked at 0x001C6BEF and shifted into place at 0x001C6BFD), bits 8..11 = 0, bits 12..15 = the number of prefix bits consumed (0x001C6BF4).
