# Copy12x12_MMX

name: Copy12x12_MMX
rva: 0x001D76A0
size: 51
ret_site: 0x001D76D2
convention: cdecl, 4 stack args, caller cleans
args: source (bytes) | destination (bytes) | source stride (uint) | destination stride (uint)
returns: none
callees: none
tables: none
fields: none

## Behaviour

Copies a 12x12 byte block as 12 rows of three 32-bit words, source and destination rows advance by their own strides. Plain integer code despite the name.
