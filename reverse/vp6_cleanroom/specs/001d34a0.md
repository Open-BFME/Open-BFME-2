# FilterVert_MMX

name: FilterVert_MMX
rva: 0x001D34A0
size: 317
ret_site: 0x001D35DC
convention: cdecl, 4 stack args, caller cleans
args: postproc instance pointer (unused) | pixel pointer (bytes) | line length (int) | bounding constant block pointer (int32 pointer)
returns: none
callees: none
tables: none
fields: none

## Behaviour

Loop filter across one block edge, 8 lines, parameterised by a prepared constant block instead of a q index: the fourth argument points at the block produced by 0x001D3230 / 0x001C7640 (the replicated 16-bit limit at byte offset 0, replicated 16-bit ones at offset 8, replicated 16-bit fours at offset 16). Per line the four pixels straddling the edge are read, the correction is the outer first-side pixel minus three times the inner first-side pixel plus three times the inner second-side pixel minus the outer second-side pixel, plus 4, arithmetically shifted right 3 (e.g. 0x001D34F7), it is bounded with the limit from the constant block (the ones at offset 8 are used for the sign mask, e.g. 0x001D3516), the inner first-side pixel is increased and the inner second-side pixel decreased by the bounded correction, clamped to 0..255. Horizontal edge: the pointer is at the first pixel below the edge, the four pixels are rows -2, -1, 0 and +1 (line length apart), lines are columns. The first argument is not used. Four lines per MMX step.
Bounding rule used by the loop filters in this library (named 'bound' below): a correction value is kept unchanged while its magnitude is below the limit, is reduced linearly beyond that so that a magnitude of twice the limit maps to zero (the response is the limit minus the distance of the magnitude from the limit), and is zero for magnitudes of twice the limit or more, the sign of the original value is preserved. The SIMD code realises this with arithmetic shifts by 15 to extract signs, saturating subtractions and a multiply by a sign mask built from the replicated 16-bit ones.
