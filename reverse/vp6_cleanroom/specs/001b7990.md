name: VP6_CreateQuantizer
rva: 0x001B7990
size: 73
ret_site: 0x001B79D8
convention: cdecl, no arguments
args: none (no arguments)
returns: pointer to a new QUANTIZER (retail quantizer instance, 0x990 bytes) or null
callees: 0x001B6400 duck_malloc, 0x001B7860 AllocateQuantizerBuffers (EAX ABI), 0x001B7930 VP6_DeleteQuantizer
tables: none
fields: none

Behaviour:
Allocates 0x990 bytes (tag 0). Returns null when that fails. Zero-fills (0x264 dwords). Calls AllocateQuantizerBuffers with the block in EAX. If it returns 0, VP6_DeleteQuantizer is called on the address of a stack copy of the pointer (which nulls it) and null is returned. Otherwise returns the block.
