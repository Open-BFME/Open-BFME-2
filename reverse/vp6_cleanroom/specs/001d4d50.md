## Behaviour

Notation used below: inputs of a 1-D transform are in0..in7, its outputs out0..out7, intermediate terms are named by role, multiplier constants by their retail value (M[c](v) = floor(v x c / 65536), see the multiplier notation paragraph), sat() = clamp to -32768..32767, wrap() = modulo 65536.
Decoder-side reduced inverse DCT (MMX path, 2..10 coefficients): the four 8-byte spans listed in the header (sixteen storage words) are dequantised with four 16-bit lane multiplies and stored directly in the internal layout, those sixteen words are the inputs in0..in3 of natural rows 0..3, the ten storage slots of the first ten transmission coefficients (words 0, 1, 2, 3, 8, 9, 10, 16, 17 and 24) lie inside them, the other six words (11, 18, 19, 25, 26 and 27) are read, multiplied and used in the same way, so the supported domain requires them to be zero, the reduced transform runs on natural rows 0..3 (0x001D4DD6-0x001D4F18, with the transposes) and then on all eight natural columns (0x001D4F19 onward) with rounding and shift. Natural rows 4..7 of the working buffer are zeroed before the passes. The value trees are identical to those of 0x001D3F30 (verified symbolically).

Value contract of the reduced 1-D transform (inputs in0..in3 only, in4..in7 are not read and are taken as zero), obtained by symbolic evaluation of this routine's instruction stream, multiplier and sat/wrap notation as in the full contract of 0x001D35E0:
- oddSum17 = M[64277](in1), oddDiff17 = M[12785](in1), oddSum35 = M[54491](in3), oddDiff35 = sat(0 - M[36410](in3)) (a saturating negation).
- oddDS = sat(oddSum17 - oddSum35), oddSS = sat(sat(oddSum35 + oddSum35) + oddDS), oddDM = sat(oddDiff17 - oddDiff35), oddSM = sat(sat(oddDiff35 + oddDiff35) + oddDM), rotS = M[46341](oddDS), rotM = M[46341](oddDM) (wrapping add-backs).
- even term: rotEven = M[46341](in0) with wrapping add-back, it serves as both the even sum and the even difference (there is no separate saturating add-back in the reduced routines).
- pairSum26 = M[60547](in2), pairDiff26 = M[25080](in2).
- second stage: eA = sat(rotEven - pairSum26), eB = sat(sat(pairSum26 + pairSum26) + eA), oA = sat(rotM - pairDiff26), oB = sat(sat(pairDiff26 + pairDiff26) + oA), fA = sat(rotEven - rotS), fB = sat(sat(rotS + rotS) + fA).
- outputs exactly as in the full contract (first pass: out7 = sat(eB - oddSS), out0 = sat(sat(oddSS + oddSS) + out7), out2/out1 from fB and oB, out4/out3 from eA and oddSM, out6/out5 from fA and oA, second pass with the saturating +8 on each pair's difference and the arithmetic shift right 4 on both results).
The reduced MMX routines (0x001D3F30, 0x001D4D50) and the reduced SSE2 routine (0x001D85C0) evaluate identical value trees.

No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
