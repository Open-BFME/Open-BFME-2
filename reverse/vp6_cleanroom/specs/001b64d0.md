name: duck_strcmp (EA shim)
rva: 0x001B64D0
size: 65
ret_site: 0x001B6510 (also 0x001B6508)
convention: cdecl
args: [esp+4] first string, [esp+8] second string
returns: 0 when equal, -1 when the first differing byte of the first string is lower, 1 when higher (unsigned byte compare)
callees: none
tables: none
fields: none

Behaviour:
Compares the two NUL-terminated strings byte by byte (two bytes per loop iteration) and returns the three-way result.
