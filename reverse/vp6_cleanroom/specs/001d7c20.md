# FilterUnpackBlock1d_vb8_wmt

name: FilterUnpackBlock1d_vb8_wmt
rva: 0x001D7C20
size: 93
ret_site: 0x001D7C7C
convention: cdecl, 7 stack args, caller cleans
args: source (bytes) | output (int16 pointer) | source pixels per line (uint) | pixel step (unused) | output height (uint) | output width (uint, output row pitch in bytes) | taps (int16 pointer)
returns: none
callees: none
tables: 0x00DB84D0 eight 16-bit 64 (rounding)
fields: none

## Behaviour

SSE2 version of the two-tap filter with the same contract as 0x001D79D0: eight outputs per row, each the sum of a sample weighted by the first eight-entry weight group (taps pointer offset 0) and the sample one row below weighted by the second group (offset 16), plus the rounding constant 64 from the listed table, arithmetically shifted right 7, stored as int16 values (16 bytes per row, output row pitch = 'output width' bytes, callers pass 16). Rows advance as in the MMX version, 'pixel step' is unused.
