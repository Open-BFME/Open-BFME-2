name: LoadFrameHeader
rva: 0x001BD050
size: 1279
ret_site: 0x001BD54E (early ret 0x001BD0C7)
convention: custom register ABI: ESI = pointer to PB_INSTANCE (retail decoder instance), no stack arguments, result in EAX
args: ESI = decoder instance pointer (register only, no stack arguments)
returns: 1 on success, 0 when the version byte exceeds 7
callees: 0x001BCFC0 ReadHeaderBits, 0x001B7050 VP6_InitQTables, 0x001BCEE0 VP6_StartDecode, 0x001B6900 SetPPInterlacedMode, 0x001B6910 SetDeInterlaceMode, 0x001BCF40 VP6_bitread, 0x001B9410 VP6_InitFrameDetails, 0x001C4F00 VP6_DecodeBool, 0x001B71C0 VP6_UpdateQ
tables: none
fields: 0x450C header reader, 0x1AC frame type, 0x944 multi-stream flag, 0x19C version, 0x19D profile, 0x13C quantizer (fields 0 Q index, 4 quality value, 0x3C threshold table), 0x1DC interlaced, 0x150 primary bool coder, 0x451C second partition offset, 0x298 post-processor, 0x4944 de-interlace mode, 0x1C8/0x1CC horizontal scale and ratio, 0x1D0/0x1D4 vertical scale and ratio, 0x1F8/0x1F4 horizontal and vertical fragments, 0x1E0/0x1E4 expanded width and height, 0x234/0x238 scale width and height, 0x1D8 scaling mode, 0x1B0/0x1B4 frame width and height, 0x264 scale buffer, 0x23C/0x240 output width and height, 0x692 prediction filter mode, 0x694 variance threshold, 0x693 motion-vector size threshold, 0x698 refresh-golden flag, 0x4534 loop filter mode, 0x4520 use-Huffman flag

Behaviour:
Reads the frame header. From the header reader: 1 bit frame type, 6 bits Q index, 1 bit multi-stream flag.
Key frame (type 0): 5 bits version, 2 bits profile. If the version exceeds 7, returns 0. Copies the Q tables into the quantizer. 1 bit interlaced flag. If multi-stream or profile 0: the primary bool coder starts at header buffer plus 4 and the second partition offset is read as 16 header bits, else the coder starts at buffer plus 2. The post-processor's interlaced mode is set, and when interlaced its de-interlace mode is set from the instance. Then through the bool coder: 8 bits vertical fragments and 8 bits horizontal fragments (each doubled), 8 bits output vertical and 8 bits output horizontal fragments (doubled). Zero horizontal or vertical ratios become 1. The old scaled width and height are computed as scale times fragments times 8 divided by ratio. Expanded width and height = output fragments times 8. The vertical scale/ratio pair becomes 1/1 when fragments are at least the output fragments, 5/4 when 5 times fragments is at least 4 times output, 5/3 when 5 times fragments is at least 3 times output, else 2/1. The same for the horizontal pair. New scaled width and height are stored in scale width and height. 2 bits scaling mode. If the fragment counts changed, frame width and height become 8 times the new counts and VP6_InitFrameDetails is called. If a scale buffer exists and the scaled size changed, its luma part ((output width plus 32) times (output height plus 32) bytes) is cleared to 0 and the following half-size chroma part to 0x80. If the profile is non-zero: a bool at 128 set means prediction filter mode 2 with the variance threshold = 5 bits shifted left 5 and the size threshold = 3 bits, otherwise the mode is a bool at 128 (1 bicubic, 0 bilinear).
Inter frame: the coder starts at buffer plus 3 with a 16-bit second partition offset when multi-stream or profile 0, else at buffer plus 1. The refresh-golden flag is a bool at 128. If the profile is non-zero, the loop filter mode is a bool at 128 and, when set, becomes 2 plus another bool at 128.
Common tail: use-Huffman flag = bool at 128. Quantizer Q index = the 6-bit value, quantizer quality value = its threshold-table entry for that index, then VP6_UpdateQ(quantizer, version). Returns 1.
