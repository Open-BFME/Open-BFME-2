## Behaviour

Reads the per-frame mode probability update for the three mode-context groups (j = 0,1,2) and then rebuilds the mode trees.

For each group j in order:
1. Decode one bool with probability 174. If it is set, read 4 raw bits giving a codebook index k (0..15) and load the 20-byte codebook vector at 0x00BD94F8 + (16j + k) x 20: byte 2i goes to row 1 entry i (bytes at +0x736+20j), byte 2i+1 goes to row 0 entry i (bytes at +0x72C+20j), for i = 0..9.
2. Decode one bool with probability 254. If it is set, then for each i = 0..9: call the mode-difference decoder, add its result to row 1 entry i and store the sum clamped to 0..255, then call it again, add to row 0 entry i and store clamped to 0..255 (row 1 is always updated before row 0 for the same i).

After all three groups, call the mode-tree builder with the instance pointer. The function has no other side effects. The bool decoder and bit reader both receive the address of the bool-coder sub-object at +0x150.
