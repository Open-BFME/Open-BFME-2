# FilterBlock1d_hb8_mmx

name: FilterBlock1d_hb8_mmx
rva: 0x001D6FF0
size: 134
ret_site: 0x001D7075
convention: cdecl, 7 stack args, caller cleans
args: source pointer (bytes) | output pointer (bytes) | source pixels per line (uint) | pixel step (uint, unused in retail) | output height (uint) | output width (uint, used as the output row pitch) | filter taps pointer (int16)
returns: none
callees: none
tables: 0x00DB81A0 eight 16-bit 64 (rounding)
fields: none

## Behaviour

Two-tap (bilinear) one-dimensional filter producing an 8-wide block of 'output height' rows. The taps pointer addresses two groups of eight identical int16 weights (byte offsets 0 and 16): the first weight applies to the sample at the output position, the second to the next sample to the right on the same row. The two weighted samples are summed in 16-bit lanes, 64 is added (rounding table listed) and the sum is arithmetically shifted right 7, then packed to a byte with unsigned saturation. Source rows advance by 'source pixels per line', output rows by 'output width' bytes, 8 pixels per row, 'pixel step' is not read. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
