name: HorizontalLine_4_5_Scale_MMX
rva: 0x001D2060
size: 232
ret_site: 0x001D2147
convention: cdecl, 4 stack args, caller cleans (ebp frame)
args: source line (bytes) | source width (uint) | destination line (bytes) | destination width (unused)
returns: none
callees: none
tables: 0x00BD9950 four 16-bit 128 (rounding) | 0x00BD9970 16-bit 205,154,102,51 | 0x00BD9980 16-bit 51,102,154,205 | 0x00BD9990 byte mask 0,0,0,0,0,0,255,0
fields: none

## Behaviour

Horizontal 4-to-5 upscale of one line. The source is consumed in groups of four pixels, each group yields five destination pixels. The first destination pixel of a group is the group's first source pixel unchanged. The second, third and fourth destination pixels are blends of consecutive source pairs - (first, second), (second, third) and (third, fourth) - with weights 51 and 205, 102 and 154, 154 and 102 respectively (the weight vectors listed), each blend being the weighted sum plus 128, shifted right 8. The fifth destination pixel blends the group's fourth pixel with the following group's first pixel with weights 205 and 51. Groups are taken while the group start is below the source width minus 4, for the final group the fifth destination pixel is a copy of the group's fourth pixel instead of a blend. The MMX body forms the four products of a group in one 16-bit multiply and assembles the five output bytes with the byte mask listed. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
