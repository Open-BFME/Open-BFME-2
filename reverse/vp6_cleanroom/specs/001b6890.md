name: CreatePostProcInstance
rva: 0x001B6890
size: 63
ret_site: 0x001B68CE
convention: cdecl
args: [esp+4] pointer to a 14-dword frame configuration
returns: pointer to a new POSTPROC_INSTANCE (retail post-processor instance, 0xC8 bytes) or null
callees: 0x001B6400 duck_malloc, 0x001B67E0 ChangePostProcConfiguration
tables: none
fields: 0xC4 add-noise mode

Behaviour:
Allocates 0xC8 bytes (tag 0). On null returns null. Zero-fills it (0x32 dwords), applies the configuration, sets the add-noise mode field to 1 and returns the instance.
