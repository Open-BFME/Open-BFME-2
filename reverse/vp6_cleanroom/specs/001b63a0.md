name: duck_free (EA shim)
rva: 0x001B63A0
size: 28
ret_site: 0x001B63B6 (ret after the virtual call), or tail jump at 0x001B63B7 to 0x00430830
convention: cdecl
args: [esp+4] block pointer
returns: void
callees: virtual slot 1 of the allocator object (thiscall-like: ECX = object, args (pointer, 0)), or 0x00430830 (engine free) when no allocator object is installed
tables: 0x00DFDA54 allocator object
fields: none

Behaviour:
If the global allocator object at 0x00DFDA54 is non-null, invokes its vtable slot 1 with the block pointer and a 0 second argument (the callee cleans the stack). Otherwise tail-jumps to the engine free routine at 0x00430830 with the original argument.
