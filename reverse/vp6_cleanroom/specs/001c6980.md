name: InsertSorted
rva: 0x001C6980
size: 88
ret_site: 0x001C69D7 (also 0x001C69C8)
convention: custom register ABI: ESI = sort record array (12 bytes per record: successor index dword, weight dword, edge dword), EDX = index of the record to insert, [esp+4] pointer to the list head index
args: ESI, EDX and one stack dword
returns: void
callees: none
tables: none
fields: none

Behaviour:
Inserts a record into a singly linked list kept in ascending weight order. The list is walked from the head while the record to insert is heavier than the current record (a record of equal weight stops the walk, 0x001C69A3..0x001C69AA, so the new record is placed before records of equal weight). If the walk stopped at the head itself, the new record becomes the head: its successor is the old head and the head index is written back through the pointer argument (0x001C69BA..0x001C69C4). Otherwise the new record is linked after the last lighter record and before the record that stopped the walk (which may be the end marker -1).
