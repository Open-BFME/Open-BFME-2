Behaviour:
Scales a plane up by 5/4 in both directions in bands of 4 source rows to 5 destination rows. Scales source row 0 into destination row 0. Then for the (destination height divided by 5, unsigned) minus 1 bands: scale source rows 1..3 into destination rows 1..3, scale source row 4 into destination row 5, run the vertical band filter on the destination band (width = destination width), then advance the source by 4 rows and the destination by 5 rows. Finally scale source rows 1..3 of the last band into destination rows 1..3 and run the last-band vertical filter.
