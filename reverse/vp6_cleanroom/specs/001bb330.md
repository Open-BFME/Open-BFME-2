name: ScaleOrCenter
rva: 0x001BB330
size: 126
ret_site: 0x001BB3AD (also 0x001BB369)
convention: cdecl
args: [esp+4] pointer to POSTPROC_INSTANCE (retail post-processor instance), [esp+8] frame buffer, [esp+0xC] pointer to a YUV buffer config
returns: void
callees: 0x001B96A0 UpdateUMVBorder, 0x001BAF30 AnyRatioFrameScale, 0x001BB190 CenterImage
tables: none
fields: 0x8 post-processing level, 0x68 scaling mode, 0x70 expanded width, 0x74 expanded height

Behaviour:
If the level field is non-zero, UpdateUMVBorder is first applied to the frame. Then by scaling mode. Modes 0 and 1 centre the expanded picture inside the config buffer: the vertical margin is half of (config Y height minus expanded height) and the horizontal margin half of (config Y width minus expanded width), both unsigned shifts (0x001BB379, 0x001BB38E). AnyRatioFrameScale is called with a luma byte offset of the vertical margin times the config Y width plus the horizontal margin, and a chroma byte offset of half the vertical margin times the config UV width plus half the horizontal margin (signed halvings at 0x001BB381 and 0x001BB392). Mode 2 calls CenterImage. Other modes do nothing.
