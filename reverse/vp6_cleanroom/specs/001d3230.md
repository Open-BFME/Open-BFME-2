# SetupBoundingValueArray_ForMMX

name: SetupBoundingValueArray_ForMMX
rva: 0x001D3230
size: 53
ret_site: 0x001D3264
convention: cdecl, 2 stack args, caller cleans
args: postproc instance (opaque struct, pointer) | filter limit (int)
returns: pointer to the prepared 32-byte-aligned constant block
callees: none
tables: none
fields: +0x34 pointer to a 512-entry int32 scratch array owned by the instance

## Behaviour

Prepares the SIMD constant block used by the MMX edge filters. Takes the int32 array pointer at +0x34, adds 1024 bytes (the array midpoint) and rounds the address down to a multiple of 32. At that address it writes six 32-bit words: words 0 and 1 are the limit replicated into both 16-bit halves (limit x 0x10001), words 2 and 3 are 0x00010001 (four 16-bit ones), words 4 and 5 are 0x00040004 (four 16-bit fours). The write order is word 1, 0, 3, 2, 5, 4. Returns the aligned address. Identical twin of 0x001C7640 except for the field used.
