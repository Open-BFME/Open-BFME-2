# ReconBlock_MMX

name: ReconBlock_MMX
rva: 0x001D77D0
size: 66
ret_site: 0x001D7811
convention: cdecl, 4 stack args, caller cleans
args: block (int16 pointer, 64 entries, row pitch 16 bytes, read only) | prediction (int16 pointer, 64 entries, row pitch 16 bytes, read only) | destination (byte pointer) | line step (uint)
returns: none
callees: none
tables: none
fields: none

## Behaviour

For each of 8 rows: loads the 8 int16 entries of the block row and of the prediction row (two 8-byte loads each, 0x001D77E9-0x001D77F3), adds them lane-wise with 16-bit wrap-around (0x001D77F7, 0x001D77FA), packs the eight sums to bytes with unsigned saturation (clamp to 0..255, 0x001D77FD) and stores the 8 bytes to the destination row (0x001D7800). Both input pointers advance 16 bytes per row, the destination by the line step. The two int16 inputs are never written, the only stores are the eight 8-byte destination writes, so the destination may alias neither input row that is still to be read. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
