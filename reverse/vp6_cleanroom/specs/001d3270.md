# FilterHoriz_MMX

name: FilterHoriz_MMX
rva: 0x001D3270
size: 551
ret_site: 0x001D3496
convention: cdecl, 4 stack args, caller cleans (ebp frame)
args: postproc instance pointer (unused) | pixel pointer (bytes, at the first of the four contributing columns of line 0) | line length (int) | filter constant/scratch block (pointer to a writable 56-byte block, see below)
returns: none
callees: none
tables: none
fields: none

## Behaviour

Loop filter across one vertical block edge, 8 lines (rows), MMX, four rows per batch. The edge lies between columns 1 and 2 relative to the pixel pointer: the contributing samples of a row are columns 0, 1, 2 and 3 (the dword loaded at column -2 is shifted right by 16 at 0x001D3288 so that only columns 0 and 1 of it survive, and the dword at column +2 supplies columns 2 and 3), columns -2 and -1 and 4 and 5 are inside the read footprint but do not contribute. Per row the correction is column 0 minus three times column 1 plus three times column 2 minus column 3, plus 4 (the fours at block offset 16, 0x001D332E), arithmetically shifted right 3 (0x001D335D), then bounded by the limit held at block offset 0 with the sign-mask built from the ones at block offset 8 (0x001D3392): the bounding keeps a correction whose magnitude is below the limit, folds it back linearly between the limit and twice the limit, and zeroes it beyond, preserving sign. Column 1 is increased and column 2 decreased by the bounded correction, clamped to 0..255 (unsigned pack), and the two bytes are written back as one 16-bit store at pointer + 1 of each row (0x001D340D, 0x001D341A, 0x001D3430, 0x001D343F for rows 0..3, 0x001D3478-0x001D348F for rows 4..7). Rows are line-length apart.

The fourth argument must point to a writable, 8-byte-aligned 56-byte block: offsets 0..7 hold the replicated 16-bit limit, 8..15 the replicated 16-bit ones and 16..23 the replicated 16-bit fours (as prepared by 0x001D3230 / 0x001C7640), while offsets 24..55 are used as scratch (transposed pixel words are stored at offsets 24, 32, 40 and 48: 0x001D32DD, 0x001D32E4, 0x001D3370, 0x001D3377, and read back as dwords at 28, 32, 44, 48 and 52). The block must not alias the pixel rows. The first argument is not read. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
