name: AnyRatioFrameScale
rva: 0x001BAF30
size: 606
ret_site: 0x001BB18D (early 0x001BB0F3)
convention: cdecl
args: [esp+4] pointer to POSTPROC_INSTANCE (retail post-processor instance), [esp+8] frame buffer, [esp+0xC] pointer to a YUV buffer config (layout as in ScaleFrame), [esp+0x10] Y byte offset into the config's Y buffer, [esp+0x14] UV byte offset
returns: int, the luma result of AnyRatio_2D_Scale (0 when the ratio is unsupported)
callees: 0x001BACA0 AnyRatio_2D_Scale (three times)
tables: none
fields: 0x58 horizontal scale, 0x5C horizontal ratio, 0x60 vertical scale, 0x64 vertical ratio, 0x70 expanded frame width, 0x74 expanded frame height, 0x40 frame width, 0xB4 border, 0x78/0x7C/0x80 recon offsets

Behaviour:
The destination luma size is the expanded frame width and height. The source luma width is the expanded width multiplied by the horizontal ratio and divided by the horizontal scale, rounding up (unsigned division at 0x001BAF50), and the source height likewise with the vertical pair (0x001BAF69).
A padded width is derived from the source width: when the horizontal ratio is 3 the source width is rounded up to a multiple of 3 (0x001BAF78..0x001BAF9B), otherwise up to a multiple of 8 (0x001BAF9F..0x001BAFB2), and the rounded value is multiplied by the horizontal scale and divided by the horizontal ratio (signed arithmetic). A padded height is derived from the source height the same way with the vertical pair.
Luma is scaled from the frame at the recon Y offset (pitch = frame width plus twice the border) into the config Y pointer plus the Y offset with the config Y stride. Then, for every padded-height row, the bytes from the destination width up to the padded width are zeroed, and the rows from the destination height up to the padded height are zeroed entirely for the padded width. If the luma scaling reported an unsupported ratio, 0 is returned.
Source and destination widths and heights are halved with rounding up (signed). Chroma U is scaled from the recon U offset (pitch = frame width halved plus the border) into the U pointer plus the UV offset with the UV stride, and V likewise. The luma result is returned.
