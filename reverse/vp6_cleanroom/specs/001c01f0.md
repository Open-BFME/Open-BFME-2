name: Bound
rva: 0x001C01F0
size: 60
ret_site: 0x001C022B
convention: cdecl
args: [esp+4] limit F (unsigned), [esp+8] signed filter value
returns: bounded filter value
callees: none
tables: none
fields: none

Behaviour:
Branch-free bounding of a filter value: take the magnitude m of the value, zero it when it is not below 2 F, then compute F minus the absolute difference between m and F, and restore the original sign. The result is 0 when the magnitude reached 2 F, rises linearly to F at magnitude F, and falls back to 0 at magnitude 2 F.
