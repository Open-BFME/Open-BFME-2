# SatUnsigned8

name: SatUnsigned8
rva: 0x001D55C0
size: 301
ret_site: 0x001D56EC
convention: cdecl, 4 stack args, caller cleans
args: result (byte pointer) | data (int16 pointer) | result line step (uint) | data line step (uint, in int16 units)
returns: none
callees: none
tables: none
fields: none

## Behaviour

Writes an 8x8 block of bytes: for each of 8 rows, each of the 8 int16 inputs is clamped to 0..255 and stored as a byte. Data advances by the data line step (int16 units), result by the result line step (bytes). Unrolled 8 wide in retail.
