# MmxReconInter

name: MmxReconInter
rva: 0x001D7560
size: 75
ret_site: 0x001D75AA
convention: cdecl, 5 stack args, caller cleans
args: scratch (unused) | destination (bytes) | reference (bytes) | residual (int16 pointer, pitch 8) | stride (uint)
returns: none
callees: none
tables: none
fields: none

## Behaviour

Inter reconstruction: destination byte = reference byte + residual, clamped to 0..255, for 8 rows of 8, reference and destination rows are stride apart, residual rows 8 entries apart. 8 pixels per step in 16-bit lanes, unsigned pack. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
