name: DeblockPlane
rva: 0x001BF8D0
size: 488
ret_site: 0x001BFAB7
convention: cdecl
args: [esp+4] pointer to POSTPROC_INSTANCE (retail post-processor instance), [esp+8] source frame, [esp+0xC] destination frame, [esp+0x10] channel (0 Y, 1 U, other V)
returns: void
callees: band routine through 0x00E22FB0 (non-filtered band) or 0x00E22FA4 (loop-filtered band) chosen by version, vertical-edge routine 0x001BE140 or 0x001BD670 likewise
tables: scale table pointers 0x00E22CF0 (Y, version 2 and up), 0x00E22CE8 (U and V, version 2 and up), 0x00E22CE4 (all planes below version 2)
fields: 0x0 version, 0x98 Y stride, 0x9C UV stride, 0x90 horizontal fragments, 0x94 vertical fragments, 0x84 Y plane fragments, 0x88 UV plane fragments, 0x78/0x7C/0x80 recon offsets

Behaviour:
Selects the band pair: version 2 and up uses the non-filtered band routine (pointer 0x00E22FB0) with DeblockVerticalEdgesInNonFilteredBand, otherwise the loop-filtered band routine (pointer 0x00E22FA4) with DeblockVerticalEdgesInLoopFilteredBand. Channel 0: line step = Y stride, across = horizontal fragments, down = vertical fragments, start fragment 0, plane at recon Y offset. Channel 1: UV stride, across and down halved, start = Y plane fragments, recon U offset. Other: start = Y plus UV plane fragments, recon V offset. The scale table is picked as listed above.
Copies the first 4 lines of the plane from source to destination. Then for band index k from 1 below down: advance both pointers by 8 lines and call the band routine (instance, source, destination, line step, across, start, scale), then start gains across. Finally copies lines 4..7 of the last band position from source to destination and calls the vertical-edge routine with the same arguments.
