## Behaviour

Notation used below: inputs of a 1-D transform are in0..in7, its outputs out0..out7, intermediate terms are named by role, multiplier constants by their retail value (M[c](v) = floor(v x c / 65536), see the multiplier notation paragraph), sat() = clamp to -32768..32767, wrap() = modulo 65536.
Reduced dequantise plus inverse DCT for blocks whose only non-zero coefficients are the first ten in transmission order (natural positions (0,0) (0,1) (1,0) (2,0) (1,1) (0,2) (0,3) (1,2) (2,1) (3,0), i.e. inside natural rows 0..3 and columns 0..3). Dequantisation reads and multiplies all 64 input and quantiser words exactly as 0x001D35E0 does (sixteen 8-byte input loads from 0x001D3F56 to 0x001D41E5 with the matching quantiser loads), scattering the products into the working buffer in the same internal layout, so the full input and quantiser blocks are part of this routine's read footprint. Three coefficient domains must be kept apart. (a) Supported domain: blocks whose non-zero coefficients are among the first ten transmission positions. The decoder calls this routine only for such blocks. (b) The reduced passes below consume the whole natural 4x4 square, rows 0..3 by columns 0..3, so the six further positions inside it, natural (3,1), (2,2), (1,3), (2,3), (3,2) and (3,3) (transmission positions 11, 12, 13, 17, 18 and 24), are read and used, and must be zero in the supported domain. A non-zero value there changes the output and matches the full transform 0x001D35E0 (retail-emulated, quantiser entries all 1, coefficient 64 at natural (1,3) only: 53 non-zero outputs, first row 3, -1, -4, -2, 2, 4, 1, -3). (c) Positions outside that square, natural rows 4..7 or columns 4..7, are multiplied and stored by the scatter but ignored by the transform, which takes them as zero (retail-emulated: coefficient 64 at natural (0,4) or (4,0) alone gives an all-zero output). First pass: the reduced transform below on natural rows 0..3 (0x001D4268-0x001D433C, inputs in0..in3 = natural columns 0..3) followed by the 4x4 transposes, second pass: the reduced transform on natural columns 0..3 (0x001D43AB-0x001D44C7) and 4..7 (from 0x001D44C8), each column's inputs in0..in3 being natural rows 0..3 (rows 4..7 zero), with the rounding and shift, the full 64-entry raster block is written.

Value contract of the reduced 1-D transform (inputs in0..in3 only, in4..in7 are not read and are taken as zero), obtained by symbolic evaluation of this routine's instruction stream, multiplier and sat/wrap notation as in the full contract of 0x001D35E0:
- oddSum17 = M[64277](in1), oddDiff17 = M[12785](in1), oddSum35 = M[54491](in3), oddDiff35 = sat(0 - M[36410](in3)) (a saturating negation).
- oddDS = sat(oddSum17 - oddSum35), oddSS = sat(sat(oddSum35 + oddSum35) + oddDS), oddDM = sat(oddDiff17 - oddDiff35), oddSM = sat(sat(oddDiff35 + oddDiff35) + oddDM), rotS = M[46341](oddDS), rotM = M[46341](oddDM) (wrapping add-backs).
- even term: rotEven = M[46341](in0) with wrapping add-back, it serves as both the even sum and the even difference (there is no separate saturating add-back in the reduced routines).
- pairSum26 = M[60547](in2), pairDiff26 = M[25080](in2).
- second stage: eA = sat(rotEven - pairSum26), eB = sat(sat(pairSum26 + pairSum26) + eA), oA = sat(rotM - pairDiff26), oB = sat(sat(pairDiff26 + pairDiff26) + oA), fA = sat(rotEven - rotS), fB = sat(sat(rotS + rotS) + fA).
- outputs exactly as in the full contract (first pass: out7 = sat(eB - oddSS), out0 = sat(sat(oddSS + oddSS) + out7), out2/out1 from fB and oB, out4/out3 from eA and oddSM, out6/out5 from fA and oA, second pass with the saturating +8 on each pair's difference and the arithmetic shift right 4 on both results).
The reduced MMX routines (0x001D3F30, 0x001D4D50) and the reduced SSE2 routine (0x001D85C0) evaluate identical value trees.

Retail-derived check vectors (obtained by executing the retail instruction streams in an emulator with the constant block initialised by 0x001C4300, quantiser entries all 1, coefficients given at natural raster positions (row, column), zero elsewhere, each result row listed in order):

All six MMX and SSE2 routines (full and reduced, where the vector lies in the reduced domain) produce these identical results, the MMX full routine's saturating and the SSE2 full routine's wrapping even-difference add-back cannot be told apart by any input, since the M[46341] add-back of a signed 16-bit value always stays within signed 16 bits.
No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
