# AverageBlock_MMX

name: AverageBlock_MMX
rva: 0x001D76E0
size: 84
ret_site: 0x001D7733
convention: cdecl, 4 stack args, caller cleans
args: reference 1 (bytes) | reference 2 (bytes) | output (int16 pointer, 64 entries pitch 8) | pixels per line (uint)
returns: none
callees: none
tables: none
fields: none

## Behaviour

Output int16 = (reference1 byte + reference2 byte) shifted right 1 (truncating) for 8 rows of 8, both references advance by pixels per line, output by 8 entries. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
