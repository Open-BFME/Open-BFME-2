# MMX_idct1

name: MMX_idct1
rva: 0x001D45F0
size: 88
ret_site: 0x001D4647
convention: cdecl, 3 stack args, caller cleans
args: input (int16 pointer) | quantiser table (int16 pointer) | output (int16 pointer, 64 entries)
returns: none
callees: none
tables: none
fields: none

## Behaviour

DC-only inverse transform. If the first input coefficient is zero, the 64 output entries are zeroed (a 32-dword string store). Otherwise the first coefficient is multiplied by the first quantiser entry (sign-extended 32-bit product), 15 is added (0x001D460D) and the result is arithmetically shifted right 5 (0x001D4610), its low 16 bits are replicated into both halves of a dword and that dword is written 32 times, giving 64 identical outputs. Plain integer code.
