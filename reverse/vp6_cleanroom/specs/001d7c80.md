# FilterBlockBil_8_wmt

name: FilterBlockBil_8_wmt
rva: 0x001D7C80
size: 204
ret_site: 0x001D7D4B
convention: cdecl, 6 stack args, caller cleans
args: reference pointer 1 (bytes) | reference pointer 2 (bytes) | output (bytes, 8x8 pitch 8) | pixels per line (uint) | mod-x (int 0..7) | mod-y (int 0..7)
returns: none
callees: 0x001D7960 FilterBlock1d_hb8_wmt | 0x001D79D0 FilterBlock1d_vb8_wmt | 0x001D7A40 FilterBlock2dBil_wmt
tables: 0x00DB84E0 bilinear filter set (SSE2 copy, same contents as 0x00DB81B0)
fields: none

## Behaviour

Chooses the one-dimensional or two-dimensional bilinear SSE2 filter from the relationship of the two reference pointers, which always differ by 0, 1, one line, one line minus 1 or one line plus 1. Let d = second pointer minus first, if d is negative the pointers are swapped and d negated. Then with p = the (possibly swapped) first pointer and stride = pixels per line:
- d equals 1: horizontal 2-tap filter of p with the bilinear phase mod-x (0x001D7960 with args (p, out, stride, 1, 8, 8, taps)), 8 rows of 8,
- d equals stride: vertical 2-tap filter of p with phase mod-y (0x001D79D0 with args (p, out, stride, stride, 8, 8, taps)),
- d equals stride - 1: 2-D bilinear filter of (p - 1) with phases mod-x, mod-y (0x001D7A40),
- d equals stride + 1: 2-D bilinear filter of p with phases mod-x, mod-y (0x001D7A40),
- any other d (including 0): nothing is written.
Phase k selects the 16-int16 entry at table + 32k. Output is the 8x8 byte block at the third argument (pitch 8).
