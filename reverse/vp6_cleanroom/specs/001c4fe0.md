name: bitread
rva: 0x001C4FE0
size: 94
ret_site: 0x001C503D
convention: custom register ABI: EAX = pointer to the raw bit reader (0x0 bits remaining in the current word, 0x4 current word, 0x8 pointer to the next unread byte), ECX = bit count, result in EAX
args: EAX = bit reader pointer, ECX = bit count (registers only)
returns: the bits as an unsigned integer
callees: none
tables: 0x00BD8D40 low-bit masks, 33 dwords (entry n has the low n bits set)
fields: none

Behaviour:
Masks the current word to its remaining bits. If the count exceeds the remaining bits: the result is the masked word shifted left by the excess, the next four bytes are loaded big-endian as the new word (pointer advanced by 4) and the excess is reduced by 32. The remaining-bits field becomes the negated (possibly reduced) excess, and the result is or-ed with the word shifted right by that new remaining count.
