name: VP6_PredictFilteredBlock
rva: 0x001C5E30
size: 768
ret_site: 0x001C612F (several earlier rets)
convention: cdecl
args: [esp+4] pointer to PB_INSTANCE (retail decoder instance), [esp+8] 16-bit output block pointer, [esp+0xC] block position (0..5)
returns: void
callees: 0x001D8DD0 (loop-filtered prediction builder: instance, source block pointer, vector x, vector y), 0x001D8A30 (16-point variance of a block: pointer, stride), function pointers 0x00E22D1C (block filter: pointer 1, pointer 2, output, stride, horizontal phase, vertical phase, bicubic flag) and 0x00E22D18 (unpack block: pointer, output, stride)
tables: 0x00BD8D00 mode-to-frame table
fields: 0x254 last recon frame, 0x24C golden frame, 0x19D profile, 0x4534 loop filter mode, 0x290 loop-filtered block buffer (stride 16), 0x692 prediction filter mode, 0x693 size threshold, 0x694 variance threshold, plus macroblock info fields 0x8, 0x24, 0x70, 0x74, 0x7C, 0x80, 0x88

Behaviour:
Source frame = golden frame when the macroblock mode maps to frame 2, else the last recon frame. Vector (x, y) = the block's vector. Phases = x and y masked with the modulus mask.
If the profile is non-zero and the loop filter mode is non-zero: the loop-filtered builder is called with (instance, source plus reconstruction index, x, y), the working block is the loop-filtered buffer with stride 16 and base offset 34 for both pointers. Otherwise: whole-pel offsets are x and y, each with the mask added when negative, then arithmetically shifted right by the vector shift, working block = source plus reconstruction index plus frame stride times the y offset plus the x offset, stride = current reconstruction stride, base offsets 0.
Pointer 2 is pointer 1 moved by plus or minus 1 when the horizontal phase is non-zero (plus when x is positive) and by plus or minus one stride when the vertical phase is non-zero (plus when y is positive).
If the two pointers are equal the block is unpacked (no filtering). Otherwise, for luma positions (below 4) both phases are doubled and: profile 0 uses the bilinear filter (flag 0). Prediction filter mode 2 (automatic): limit = (1 shifted left (size threshold minus 1)) shifted left 2 when the threshold is positive, else 128. If the threshold is non-zero and either vector component's magnitude exceeds the limit, bilinear. Else if the variance threshold is non-zero, bicubic when the block variance (from 0x001D8A30) is at least the threshold. Else bicubic. Any other prediction filter mode uses bicubic when the mode equals 1. Chroma positions (4, 5) always use bilinear with the undoubled phases.
