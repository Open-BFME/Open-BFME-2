name: VP6_DecodeMacroBlock
rva: 0x001C66B0
size: 705
ret_site: 0x001C6970
convention: cdecl
args: [esp+4] pointer to PB_INSTANCE (retail decoder instance), [esp+8] macroblock row, [esp+0xC] macroblock column
returns: void
callees: 0x001C5100 nDecodeBool, 0x001C63F0 VP6_decodeModeAndMotionVector, 0x001C61F0 VP6_DecodeBlock (six times)
tables: none
fields: 0x1DC interlaced configuration flag, 0x6E8 interlaced probability byte, 0x1AC frame type, 0x1B8 Y stride, 0x1BC UV stride, 0x21C/0x220/0x224 recon Y/U/V offsets, 0x10C/0x110/0x114 above context arrays, 0xCC/0xDC/0xEC/0xFC left contexts, 0x124/0x12C/0x134 last-DC arrays, plus macroblock info fields 0x8, 0x64, 0x68, 0x70, 0x74, 0x78, 0x7C, 0x80, 0x88, 0xBC, 0xC0, 0xC4, 0xC8

Behaviour:
Macroblock info layout: macroblock info at the start of the instance: 0x4 coefficient buffer, 0x8 macroblock mode, 0xC block modes (6 dwords), 0x24 block motion vectors (6 pairs of signed 16-bit x,y), 0x3C nearest inter vector, 0x40 near inter vector, 0x44 nearest inter index, 0x48 nearest golden vector, 0x4C near golden vector, 0x50 nearest golden index, 0x64 block row pixel offset, 0x68 block column pixel offset, 0x70 reconstruction index, 0x74 current reconstruction stride, 0x78 plane, 0x7C motion vector shift, 0x80 motion vector modulus mask, 0x88 frame reconstruction stride, 0xBC above context pointer, 0xC0 left context pointer, 0xC4 last-DC array pointer, 0xC8 interlaced flag.
Interlace flag: when the configuration is interlaced, p = the interlaced probability byte, and for columns above 3 p is lowered by half of itself when the previous macroblock was interlaced or raised by half of (256 minus p) otherwise, the macroblock interlaced flag is a bool decoded with p on the primary coder. Otherwise the flag is 0.
On a key frame the mode is set to 1 (intra), otherwise the mode and vectors are decoded.
Luma: current stride = Y stride, or twice it when interlaced (then the lower block row is 1 line below instead of 8). Last-DC pointer = last DC Y. Row pixel offset = row times 16, column pixel offset = column times 16, reconstruction index = recon Y offset plus row offset times Y stride plus column offset, frame stride = Y stride, plane 0, vector shift 2, modulus mask 3. Block 0 with above = above-Y entry (2 times column) and left = left Y row 0. Block 1: index plus 8, above entry plus 1, same left. Block 2: index = block 0's plus (8 or 1) lines, above entry (2 times column), left = left Y row 1. Block 3: plus 8, above entry plus 1, left Y row 1.
Chroma: stride and frame stride = UV stride, vector shift 3, mask 7, row offset = row times 8, column offset = column times 8. Block 4: plane 1, index = recon U offset plus row offset times UV stride plus column offset, above = above-U entry (column), left = left U, last-DC = last DC U. Block 5: plane 2, recon V offset, above-V entry, left V, last DC V.
Each block is decoded and reconstructed by VP6_DecodeBlock(instance, row, column, position).
