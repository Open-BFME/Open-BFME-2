# FilteringVert_12_MMX

name: FilteringVert_12_MMX
rva: 0x001D1DA0
size: 483
ret_site: 0x001D1F82
convention: cdecl, 3 stack args, caller cleans
args: q index (uint) | pixel pointer (bytes) | pitch (int)
returns: none
callees: none
tables: 0x00E229E0 replicated loop-filter limits (64 x 4 int16)
fields: none

## Behaviour

Loop filter across one block edge, 12 lines. For every line the four pixels straddling the edge are read (two on each side). A correction is formed as: the outer pixel of the first side, minus three times the inner pixel of the first side, plus three times the inner pixel of the second side, minus the outer pixel of the second side, plus 4 (rounding, 16-bit 4s kept on the stack, e.g. 0x001D1752), arithmetically shifted right 3 (e.g. 0x001D1780). The correction is then bounded (see below) with the limit for the given q index, read as the replicated 16-bit entry at 0x00E229E0 + 8 x (q index) (table filled by 0x001D1610). The inner pixel of the first side is increased by the bounded correction and the inner pixel of the second side decreased by it, both clamped to 0..255 (unsigned pack). The edge is horizontal: the pointer addresses the first pixel below the edge, so the four pixels are at row offsets -2 x pitch, -pitch, 0 and +pitch, and successive lines are successive columns. Four lines per MMX step.
Bounding rule used by the loop filters in this library (named 'bound' below): a correction value is kept unchanged while its magnitude is below the limit, is reduced linearly beyond that so that a magnitude of twice the limit maps to zero (the response is the limit minus the distance of the magnitude from the limit), and is zero for magnitudes of twice the limit or more, the sign of the original value is preserved. The SIMD code realises this with arithmetic shifts by 15 to extract signs, saturating subtractions and a multiply by a sign mask built from the replicated 16-bit ones.
