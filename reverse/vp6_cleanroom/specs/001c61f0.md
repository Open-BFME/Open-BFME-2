name: VP6_DecodeBlock (EA helper split out of the macroblock decoder)
rva: 0x001C61F0
size: 511
ret_site: 0x001C63EE (also 0x001C6325, 0x001C63A6)
convention: cdecl
args: [esp+4] pointer to PB_INSTANCE (retail decoder instance), [esp+8] macroblock row (unused), [esp+0xC] macroblock column (unused), [esp+0x10] block position
returns: void
callees: 0x001C5310 Huffman token reader (instance, coefficients, plane non-zero), 0x001BC3D0 bool token reader (instance, coefficients, plane non-zero, above context, left context), 0x001C5180 VP6_PredictDC (macroblock info, position, last-DC pointer, above, left), 0x001C6130 VP6_ReconstructBlock, IDCT pointers in the 65-entry table at 0x00E22D40: entry 1 (0x00E22D44), entry 9 (0x00E22D64), entry 63 (0x00E22E3C), each called as (coefficients, dequantiser, output)
tables: 0x00BD8760 plane selector per position, 0x00BD8D00 mode-to-frame table
fields: 0x4520 use-Huffman flag, 0x4 coefficient buffer (128 bytes per position), 0x78 plane, 0xBC above context, 0xC0 left context, 0xC4 last-DC pointer, 0xC block modes, 0x8 mode, 0x13C quantizer (0x180 dequantiser pointers by plane selector), 0x270 reconstruction coefficient buffer

Behaviour:
Coefficients for the position = buffer plus 128 times the position. Reads the block's tokens with the Huffman reader when the use-Huffman flag is set, else the bool reader, obtaining the end-of-block count. Applies DC prediction. Copies the block mode for the position into both the left and above context modes, the (predicted) first coefficient into both context DCs, and the mode-to-frame value of the macroblock mode into both context frames.
Inverse transform selected by the end-of-block count: at most 1 uses table entry 1 and then zeroes the first coefficient, at most 10 uses entry 9 and then zeroes coefficients 0..7, 8..11, 16..19, 24..27 and 32, otherwise entry 63 and all 64 are zeroed. The dequantiser is the quantizer's pointer for the position's plane selector and the output is the reconstruction coefficient buffer. Then VP6_ReconstructBlock(instance, position).
