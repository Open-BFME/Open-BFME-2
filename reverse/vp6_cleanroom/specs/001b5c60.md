Behaviour:
Produces the output plane description for the caller, running post-processing first when needed.
1. Reads the timestamp counter (start). Sets the level field from VP6_PickPostProcessingLevel.
2. If the level is non-zero, or the frame is interlaced and de-interlacing is on:
   a. If the post-process buffer (0x25C) is null it is allocated lazily: size = recon Y plane size plus twice the recon UV plane size plus 32 plus Y stride, tag 0, raw pointer to 0x260 and the 32-byte-rounded pointer to 0x25C, then AllocatePostProcBuffers is called on the post-processor.
   b. PostProcess is called with (post-processor, version byte, frame type byte, level', average frame Q index, last recon frame, post-process buffer, fragment info pointer, element size 4, coded mask 1). level' is level minus 200 when the level exceeds 200, level minus 100 when it exceeds 100, else the level. After the call the end timestamp is read. In the above-200 case vp6_showinfo(instance) is then called, in the above-100 case vp6_showinfo2(instance).
3. If the black clamp field is non-zero, the clamp routine pointer at 0x00E22FC8 is called with (post-processor, black clamp, white clamp, post-process buffer, post-process buffer).
4. If width is below output width OR height is below output height (scaled output path): Y width = output width plus 32, Y height = output height plus 32, Y stride = Y width, UV width = Y width divided by 2 (signed), UV height = Y height divided by 2, UV stride = UV width. Y pointer = scale buffer, U pointer = scale buffer plus Y width times Y height, V pointer = U pointer plus UV width times UV height. ScaleOrCenter is called with the post-process buffer when the level is non-zero, otherwise with the last recon frame. Afterwards the Y pointer is advanced by ((Y height minus output height) divided by 2) rows of Y stride plus (Y width minus output width) divided by 2 columns, Y width and height are replaced by the output width and height, the U and V pointers are advanced by ((UV height minus half the output height) divided by 2) rows of UV stride plus (UV width minus half the output width) divided by 2 columns, and UV width and height become half the output width and height. (Divisions here are unsigned shifts.)
   Otherwise (unscaled path): Y width/height = frame width/height, Y stride = field 0x1B8, UV width/height = half of those, UV stride = field 0x1BC. The source buffer is the post-process buffer when the level is non-zero or interlaced-with-deinterlace, else the last recon frame. Y pointer = buffer plus recon Y offset plus 48 times (Y stride plus 1). U pointer = buffer plus recon U offset plus 24 times (UV stride plus 1). V pointer likewise with the recon V offset.
5. Calls the system-state clear routine pointer at 0x00E22D10. Computes duration = (end minus start) divided by processor frequency, where end is the value read after PostProcess (or stack garbage if PostProcess did not run, matching retail). Index = level modulo 10. If the average post-process time entry at that index is 0 it is set to duration, otherwise it becomes (7 times the entry plus duration) shifted right by 3.
