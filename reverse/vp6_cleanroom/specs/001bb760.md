args: [esp+4] pointer to PB_INSTANCE (retail decoder instance), [esp+8] block position (0..5)

callees: 0x001C5E30 VP6_PredictFilteredBlock(instance, temp buffer, block position), function pointers 0x00E22F64 (inter reconstruction: temp, destination, reference, coefficients, stride), 0x00E22F68 (block reconstruction: temp, coefficients, destination, stride), 0x00E22F6C (intra reconstruction: temp, destination, coefficients, stride)
tables: 0x00DB7040 ten dwords, one per coding mode, non-zero when the mode uses motion compensation: 0,0,1,1,1,0,1,1,1,1
fields: 0x8 macroblock coding mode, 0x70 reconstruction index, 0x74 current reconstruction stride, 0x270 reconstruction coefficient buffer (64 shorts), 0x284 temporary data buffer, 0x25C post-process buffer, 0x254 last recon frame, 0x24C golden frame

Behaviour:
Zeroes the 64-short coefficient buffer. Then by the macroblock mode: mode 0 reconstructs inter from the last frame (destination and reference both at the reconstruction index into the post-process buffer and the last frame). If the mode's table entry is non-zero, computes the filtered prediction into the temp buffer via VP6_PredictFilteredBlock and reconstructs it into the post-process buffer. Mode 5 reconstructs inter from the golden frame. Any other mode reconstructs intra. All calls use the current reconstruction stride.
