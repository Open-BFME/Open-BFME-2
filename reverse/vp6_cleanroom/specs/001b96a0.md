name: UpdateUMVBorder
rva: 0x001B96A0
size: 1047
ret_site: 0x001B9AB6
convention: cdecl
args: [esp+4] pointer to POSTPROC_INSTANCE (retail post-processor instance), [esp+8] frame buffer base pointer
returns: void
callees: none (byte fills and row copies are inlined)
tables: none
fields: 0xB4 border width, 0x98 Y stride, 0x9C UV stride, 0x94 vertical fragments, 0x90 horizontal fragments, 0x78/0x7C/0x80 recon Y/U/V data offsets

Behaviour:
Extends each plane of the frame into its surrounding border by replication, so motion vectors may point outside the picture.
Y plane: let B = border, S = Y stride, rows = 8 times vertical fragments. The left edge column (first pixel of each row, starting at buffer plus recon Y offset) is replicated B bytes to its left and the right edge pixel (last pixel of each row) is replicated B bytes to its right, for every row. Then the B rows above the plane are each overwritten with a copy of the first picture row (S bytes each, starting at buffer plus B times S), and the B rows below the plane with a copy of the last picture row.
U plane: same with stride = UV stride, rows = 4 times vertical fragments, width = 4 times horizontal fragments, and a border of B halved for both the side fills and the row copies. The top rows copied are the row at recon U offset minus B halved (that is, starting from the already side-extended row) and the extension copies full UV stride rows.
V plane: identical to the U plane using the recon V offset.
