Behaviour:
Decodes one compressed frame.
1. Reads the start timestamp. Stores the byte count into field 0x1E8. Initialises the header reader at 0x450C from the buffer pointer. Calls VP6_LoadFrame, returning -1 if it fails.
2. If the multi-stream flag is set or the profile byte is 0: when the use-Huffman flag is set, the raw bit reader at 0x190 is reset (bits in remainder 0, remainder 0, position = buffer plus second-partition offset). Otherwise the second bool decoder at 0x170 is started on buffer plus second-partition offset. (The retail body does not store a bool-coder selection pointer: the macroblock decoder picks the coder itself.)
3. Calls VP6_DecodeFrameMbs. Swaps the this-frame and last-frame reconstruction pointers (0x244 and 0x254). Calls UpdateUMVBorder(post-processor, new last frame).
4. If the frame type byte is 0 (key frame) or the refresh-golden flag is set, copies recon Y plane size plus twice the recon UV plane size bytes from the last frame into the golden frame.
5. Calls the system-state clear routine pointer. Updates the average frame Q index: on a key frame it becomes the quantizer's frame Q index, otherwise (3 times the old average plus the new index plus 2) divided by 4.
6. Reads the end timestamp, duration = difference divided by processor frequency, stores it in 0x910, and sets the average decode time to duration when it was 0 or to (7 times the average plus duration) shifted right by 3.
7. Diagnostic that is live in retail: if the primary bool decoder's byte position (field 0x160) exceeds the frame size, the file "badframes.stt" is opened for append and one line is written with the format at 0x00BD7820 and the values (global frame counter, position, frame size), then closed.
8. Increments the global frame counter at 0x00DFDA50 and returns 0.
