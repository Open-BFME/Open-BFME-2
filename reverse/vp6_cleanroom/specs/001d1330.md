## Behaviour

Adds pseudo-random Gaussian noise to a plane, with a pre-clamp so that the addition cannot overflow.

Noise distribution (per call): the spread parameter is 1.0 plus (63 minus the quality index) times the double at 0x00BD7858 (0.012698412698412698, the 1.0 is at 0x00BBCC70). A 256-entry signed-byte table is filled by walking the integers from -32 (double at 0x00BD7850) up to but not including 32 (0x00BD7848): for each integer x the normal density at x for that spread (callee 0x001B6970 with arguments spread, 0.0 from 0x00BBBC20, x) is multiplied by 256 (0x00BC5D88), 0.5 (0x00BC26F8) is added and the result truncated to an integer (CRT routine 0x00629228), that many consecutive table entries are set to the byte value x. Entries not reached by the walk are set to 0. A 2048-byte noise buffer is then filled: each entry is the table entry selected by the low 8 bits of a CRT random number (import slot 0x00BBA50C). Three 16-byte clamp vectors are prepared from the table's first entry: 'low' and 'high' both hold its negation replicated, 'both' holds minus twice it.

Application: for every row (none when the height is 0) a fresh window into the noise buffer is chosen by the low 8 bits of another random number, the row is processed 16 pixels at a time while the column index is below the width (so the width is rounded up to a multiple of 16): each group is lowered by 'low' with unsigned saturation, raised by 'both' with unsigned saturation, lowered by 'high' with unsigned saturation, and the corresponding 16 noise bytes are added with wrap-around before the group is stored back in place. Rows are pitch bytes apart.

SSE2 specifics: 16 pixels per step using unaligned 128-bit loads/stores (0x001D14F6-0x001D1513), an emms is executed at entry (0x001D134E), the noise buffer has no constant initialiser.
