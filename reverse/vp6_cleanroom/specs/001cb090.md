# PlaneAddNoise_mmx

name: PlaneAddNoise_mmx
rva: 0x001CB090
size: 11476
ret_site: 0x001CDD63
convention: cdecl, 5 stack args, caller cleans (ebx-based frame, 16-byte aligned stack, 0x988-byte locals)
args: plane start (byte pointer) | width (uint) | height (uint) | pitch (int) | quality index (int)
returns: none
callees: 0x001B6970 normal density (double spread, double centre, double x) returns double | 0x00629228 CRT float-to-int | import 0x00BBA50C rand
tables: doubles at 0x00BD7858, 0x00BD7850, 0x00BD7848, 0x00BBCC70, 0x00BBBC20, 0x00BC26F8, 0x00BC5D88 (see behaviour)
fields: none

## Behaviour

Adds pseudo-random Gaussian noise to a plane, with a pre-clamp so that the addition cannot overflow.

Noise distribution (per call): the spread parameter is 1.0 plus (63 minus the quality index) times the double at 0x00BD7858 (0.012698412698412698, the 1.0 is at 0x00BBCC70). A 256-entry signed-byte table is filled by walking the integers from -32 (double at 0x00BD7850) up to but not including 32 (0x00BD7848): for each integer x the normal density at x for that spread (callee 0x001B6970 with arguments spread, 0.0 from 0x00BBBC20, x) is multiplied by 256 (0x00BC5D88), 0.5 (0x00BC26F8) is added and the result truncated to an integer (CRT routine 0x00629228), that many consecutive table entries are set to the byte value x. Entries not reached by the walk are set to 0. A 2048-byte noise buffer is then filled: each entry is the table entry selected by the low 8 bits of a CRT random number (import slot 0x00BBA50C). Three 8-byte clamp vectors are prepared from the table's first entry: 'low' and 'high' both hold its negation replicated, 'both' holds minus twice it.

Application: for every row (none when the height is 0) a fresh window into the noise buffer is chosen by the low 8 bits of another random number, the row is processed 8 pixels at a time while the column index is below the width (so the width is rounded up to a multiple of 8): each group is lowered by 'low' with unsigned saturation, raised by 'both' with unsigned saturation, lowered by 'high' with unsigned saturation, and the corresponding 8 noise bytes are added with wrap-around before the group is stored back in place. Rows are pitch bytes apart.

MMX specifics: 8 pixels per step. One emms is executed at 0x001CDB2F, after the noise-buffer initialiser and before the distribution is built, nothing clears the MMX state at exit (the pixel loop leaves MMX registers in use). Retail quirk responsible for the 11 KB size: the 2048-byte noise buffer is a stack array with a constant initialiser emitted as 1701 individual byte stores (immediate, or via al/dl/cl preloaded with 0xFE, 2 and 1) starting at 0x001CB0B4, followed by a zero fill of the remaining 347 bytes with a string store, every one of those bytes is overwritten by the buffer fill before being read, so the initial contents never affect output. An implementation that must match bytes has to reproduce that initialiser (values are the immediates of those stores, in stack order), one that only needs behaviour may omit it.
