ret_site: 0x001BFD05 (also 0x001BFCE0)
convention: cdecl
args: [esp+4] pointer to POSTPROC_INSTANCE (retail post-processor instance), [esp+8] source frame, [esp+0xC] destination frame
returns: void
callees: 0x001BD590 SetupDeblockValueArray_Generic, 0x001BFAC0 DeblockPlaneNew, 0x001BF8D0 DeblockPlane
tables: 0x00E22CEC limit table pointer, 0x00E22CF0 Y scale table pointer, 0x00E22CE8 UV scale table pointer
fields: 0x8C unit fragments, 0x28 fragment variances, 0x0 version, 0xC frame Q index, 0x38 deblock value pointer, 0x98/0x9C strides, 0x90/0x94 fragment counts, 0x78/0x7C/0x80 recon offsets

Behaviour:
Zeroes the fragment variance array (unit fragments dwords). If the version is at least 2, builds the deblock bounding array from the limit for the frame Q index and stores its centre in field 0x38 (below version 2 no array is built here). Then if the version is at least 5: DeblockPlaneNew for Y (Y stride, start 0, horizontal and vertical fragments, source and destination at recon Y offset, Y scale table), then for U and V (UV stride, start 0, fragment counts halved, recon U and V offsets, UV scale table). Otherwise DeblockPlane is called for channels 0, 1 and 2.
