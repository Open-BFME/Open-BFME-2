name: bitShift
rva: 0x001C5070
size: 60
ret_site: 0x001C50AB
convention: custom register ABI: EAX = pointer to the raw bit reader (0x0 bits remaining in the current word, 0x4 current word, 0x8 pointer to the next unread byte), ECX = bits to consume
args: EAX = bit reader pointer, ECX = bits to consume (registers only)
returns: void
callees: none
tables: none
fields: none

Behaviour:
Subtracts the count from the remaining bits. If the result is negative, loads the next four bytes big-endian as the new word (pointer advanced by 4) and adds 32 to the remaining bits.
