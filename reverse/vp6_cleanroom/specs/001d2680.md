# VerticalBand_1_2_Scale_MMX

name: VerticalBand_1_2_Scale_MMX
rva: 0x001D2680
size: 86
ret_site: 0x001D26D5
convention: cdecl, 3 stack args, caller cleans (ebp frame)
args: band pointer (bytes, row 0) | pitch (uint) | width (uint)
returns: none
callees: none
tables: 0x00BD9960 four 16-bit 1 (rounding)
fields: none

## Behaviour

Vertical 1-to-2 interpolation: row 1 of the band is replaced, column by column, by the rounded-up average of rows 0 and 2 (sum plus 1, shifted right 1, computed in 16-bit lanes and packed back to bytes). Eight columns per step, the width is rounded up to a multiple of 8. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
