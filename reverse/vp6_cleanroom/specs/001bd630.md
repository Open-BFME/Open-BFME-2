name: SetupDeblocker
rva: 0x001BD630
size: 64
ret_site: 0x001BD66F (also 0x001BD654)
convention: cdecl
args: [esp+4] pointer to POSTPROC_INSTANCE (retail post-processor instance)
returns: void
callees: 0x001BD590 SetupDeblockValueArray_Generic, or the function pointer at 0x00E22F80 (platform deblock-array builder) when the version field is below 2
tables: limit table pointer at 0x00E22CEC (points at a 64-dword table chosen by InitPostProcessing, indexed by frame Q index)
fields: 0x0 version, 0xC frame Q index, 0x38 deblock value pointer

Behaviour:
Reads the limit for the current frame Q index from the table addressed by 0x00E22CEC. If the version field is at least 2 calls the generic array builder, otherwise the pointer at 0x00E22F80, with (instance, limit), and stores the returned centre pointer in field 0x38.
