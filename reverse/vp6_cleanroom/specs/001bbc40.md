Behaviour:
Converts the zero-run tree probabilities into one weight per run symbol (symbols 0..8). Tree topology as observed from the retail dependencies: node 0 separates symbols 0..3 (probability side) from symbols 4..8. Node 1 separates 0..1 from 2..3, node 2 separates 0 from 1, node 3 separates 2 from 3. Node 4 separates 4..7 from symbol 8 (which therefore has only two branch factors). Node 5 separates 4..5 from 6..7, node 6 separates 4 from 5, node 7 separates 6 from 7. The first-named side of each node takes the node's probability byte and the other side 255 minus it.
Each symbol's weight is the product of its branch values from the root downward in unsigned 32-bit arithmetic with a shift right by 8 after every multiplication (sites 0x001BBC57..0x001BBC5D for symbol 0, through 0x001BBD46..0x001BBD49 for symbol 8). Results are stored as dwords at the symbol index (0x001BBC60, 0x001BBC74, 0x001BBC95, 0x001BBCA9, 0x001BBCD4, 0x001BBCE8, 0x001BBD1A, 0x001BBD2E, 0x001BBD4D).
