name: VP6_DeletePBInstance
rva: 0x001B56A0
size: 66
ret_site: 0x001B56E1
convention: cdecl
args: [esp+4] pointer to a pointer to PB_INSTANCE (retail decoder instance, 0x4954 bytes)
returns: void
callees: 0x001B5530 VP6_DeleteTmpBuffers, 0x001B7930 VP6_DeleteQuantizer, 0x001B68D0 DeletePostProcInstance, 0x001B6410 duck_free
tables: none
fields: 0x13C quantizer pointer (address passed to the quantizer deleter), 0x298 post-processor pointer (address passed to the post-processor deleter)

Behaviour:
If the instance pointer is non-null: delete the temporary buffers, delete the quantizer (passing the address of field 0x13C so it is nulled), delete the post-processor instance (address of field 0x298).
Then unconditionally frees the instance pointer itself (free of null is permitted by the shim) and stores null through the double pointer.
