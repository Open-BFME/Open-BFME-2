convention: cdecl
args: [esp+4] instance (unused), [esp+8] pixel pointer on the row just below a horizontal edge, [esp+0xC] line length, [esp+0x10] bounding array centre pointer
returns: void
callees: none
tables: clamp table: 768 bytes allocated at 0x00E23000..0x00E232FF with its zero point at 0x00E23100, so the byte at the zero point plus a signed offset s (s from -256 to 511) holds s clamped to 0..255. Filled by InitPostProcessing. Consumers add the signed pixel sum directly to the zero-point address
fields: none

Behaviour:
For 8 columns: with pixels a (two lines up), b (one line up), c (this row), d (one line down), filter value = a minus 3 b plus 3 c minus d mapped through the bounding array at (value plus 4) shifted right 3. Pixel b gains and pixel c loses the mapped value through the clamp table. The pointer advances one pixel per column.
