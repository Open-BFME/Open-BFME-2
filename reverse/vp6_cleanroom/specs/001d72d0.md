# FilterBlock2d_mmx

name: FilterBlock2d_mmx
rva: 0x001D72D0
size: 83
ret_site: 0x001D7322
convention: cdecl, 5 stack args, caller cleans (256-byte local buffer)
args: source pointer (bytes) | output pointer (bytes, 8x8 pitch 8) | source pixels per line (uint) | horizontal taps (int16 pointer) | vertical taps (int16 pointer)
returns: none
callees: 0x001D6C90 FilterBlock1d_h_mmx | 0x001D6D70 FilterBlock1d_v_mmx
tables: none
fields: none

## Behaviour

Separable 4-tap (bicubic) 2-D filter. Calls the horizontal filter on (source - one line) producing 11 rows of 8 into a 256-byte stack buffer with row pitch 8 (args: source - stride, buffer, stride, 1, 11, 8, h-taps), then the vertical filter starting at buffer row 1 producing 8 rows into the output (args: buffer + 8, output, 8, 8, 8, 8, v-taps). The vertical pass therefore uses buffer rows 0..10 (one above and two below each output row).
