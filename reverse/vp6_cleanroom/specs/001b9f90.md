Behaviour:
Horizontally upsamples 3 input pixels to 5 outputs per group. Number of full groups = ((source width minus 4) divided by 3, unsigned) plus 1, loop skipped when source width is exactly 3. Per group: output 0 is input 0, then the 3-to-5 weights: outputs are (102 a plus 154 b plus 128) shifted right 8, (205 b plus 51 c plus 128) shifted right 8, (51 b plus 205 c plus 128) shifted right 8, (154 c plus 102 d plus 128) shifted right 8 (a, b, c are inputs 0..2 and d is input 3 of the next group). Source advances 3, destination 5.
A final group follows in which output 4 is a copy of input 2 instead of a blend with the next group's first input.
