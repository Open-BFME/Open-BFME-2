# LastVerticalBand_1_2_Scale_MMX

name: LastVerticalBand_1_2_Scale_MMX
rva: 0x001D26E0
size: 31
ret_site: 0x001D26FE
convention: cdecl, 3 stack args, caller cleans
args: band pointer (bytes, row 0) | pitch (uint) | width (uint)
returns: none
callees: none

## Behaviour

Last band of the 1-to-2 vertical scale: row 1 is a copy of row 0, 8 bytes per step (width rounded up to a multiple of 8).
