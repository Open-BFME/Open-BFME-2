# CopyBlockMMX

name: CopyBlockMMX
rva: 0x001D7630
size: 110
ret_site: 0x001D769D
convention: cdecl, 3 stack args, caller cleans
args: source (bytes) | destination (bytes) | stride (uint)
returns: none
callees: none
tables: none
fields: none

## Behaviour

Copies an 8x8 byte block: 8 rows of 8 bytes, both source and destination advancing by the same stride. Done as two groups of four 64-bit loads/stores. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
