# ClampLevels_mmx

name: ClampLevels_mmx
rva: 0x001CDE70
size: 232
ret_site: 0x001CDF57
convention: cdecl, 5 stack args, caller cleans (ebx-based frame with 16-byte aligned stack)
args: postproc instance (opaque struct, pointer) | black clamp (int) | white clamp (int) | source (byte pointer) | destination (byte pointer)
returns: none
callees: none
tables: none
fields: +0x78 luma plane byte offset | +0x90 luma blocks across | +0x94 luma blocks down | +0x98 luma stride

## Behaviour

SIMD luma level clamp (8 pixels per step). Builds three 8-byte constant vectors on the stack: the black clamp replicated, the white clamp replicated, and (black + white) replicated (all as unsigned bytes). Width is blocks-across x 8, height is blocks-down x 8, both pointers are offset by the luma plane offset. For each row and each group of 8 pixels (column index stepping by 8 while it is below the width): load from the source, subtract the black vector with unsigned saturation, add the (black+white) vector with unsigned saturation, subtract the white vector with unsigned saturation, store to the destination. The net effect is clamping every byte into [black, 255 - white]. Rows advance by the luma stride. A width that is not a multiple of 8 is processed up to the next multiple. Nothing happens for zero height. Reads the source and writes the destination (opposite of the generic version at 0x001C74B0).
