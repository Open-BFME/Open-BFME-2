tables: writes the 768-byte clamp table spanning 0x00E23000..0x00E232FF whose zero point is 0x00E23100 (signed index from -256 to 511, stores at 0x001B653B), 0x00E22CF0 (V2 pointer), 0x00E22CE8 (UV pointer), 0x00E22CE4 (V1 pointer), 0x00E22BE0 dering modifier table (64 dwords, copied from the V1 table), 0x00E22CE0 loop-filter limit table pointer, 0x00E22CEC deblock limit table pointer
        candidate limit tables: version 6 and up 0x00DB7728 (loop filter) and 0x00DB7328 (deblock), version 5 uses 0x00DB7628 and 0x00DB7228, older uses 0x00DB7528 and 0x00DB7128. Each is 64 dwords indexed by Q index.
fields: none

Behaviour:
Fills the clamp table: for every signed offset from -256 to 511 the byte at the zero point 0x00E23100 plus the offset is set to the offset clamped into 0..255, so the allocation runs from 0x00E23000 to 0x00E232FF (loop 0x001B6520..0x001B6547). Consumers index the table by adding a signed pixel sum to the zero-point address. Records the three scale-table pointers in the globals listed. Copies all 64 dwords of the V1 table into the dering modifier table at 0x00E22BE0. Selects the loop-filter and deblock limit tables by version (6 or more, 5, otherwise) and stores their addresses in 0x00E22CE0 and 0x00E22CEC. Finally calls PostProcMachineSpecificConfig with the version.
