# ClampLevels_C

name: ClampLevels_C
rva: 0x001C74B0
size: 204
ret_site: 0x001C757B
convention: cdecl, 5 stack args, caller cleans
args: postproc instance (opaque struct, pointer) | black clamp (int) | white clamp (int) | buffer A (byte pointer) | buffer B (byte pointer)
returns: none
callees: none
tables: none
fields: +0x78 byte offset of the luma plane inside a frame buffer | +0x90 luma block count across | +0x94 luma block count down | +0x98 luma stride (bytes)

## Behaviour

Generic (non-SIMD) luma level clamp. Builds a 256-entry byte lookup on the stack where entry i is i, except that entries below the black clamp are replaced by the black clamp value and entries above (255 - white clamp) are replaced by (255 - white clamp). Then, over a region of width (blocks across x 8) and height (blocks down x 8) starting at (buffer + luma offset) in both buffers, with the luma stride between rows, each byte read from buffer B is translated through the lookup and written to the same position in buffer A. Note the direction: this version reads the fifth argument and writes the fourth (the SIMD versions at 0x001CDE70 and 0x001CDD70 go the other way). Rows and columns are plain scalar loops, a zero width or height does nothing.
