# LoopDeringBlock

name: LoopDeringBlock
rva: 0x001D8B40
size: 655
ret_site: 0x001D8DCE
convention: cdecl, 5 stack args, caller cleans (0x30-byte locals)
args: decoder instance pointer | block pointer (bytes, filtered in place) | stride (uint) | width (uint) | height (uint)
returns: none
callees: none
tables: none
fields: +0x453C dering threshold table (256 x uint32)

## Behaviour

In-place adaptive smoothing of a width x height block, unreferenced in retail. First the smallest and largest byte in the block are found (0x001D8B60-0x001D8B93). A threshold is then chosen as the larger of two table entries - the entry indexed by the largest value and the entry indexed by 255 minus the smallest value - increased by the difference between largest and smallest divided by 32 (signed shift, 0x001D8BCF-0x001D8BD2).

Horizontal pass, row by row: every pixel is replaced by the rounded mean (sum plus 2, shifted right 2) of four samples - the pixel counted twice, its left neighbour and its right neighbour - except that a neighbour whose absolute difference from the pixel exceeds the threshold is replaced in the mean by the pixel itself. One pixel outside the block is read on each side. The new values of a row are collected in a 16-byte stack buffer and copied over the row only after the whole row is computed (0x001D8C7B-0x001D8C91), so within a row the original values are used throughout.

Vertical pass, column by column over the horizontally smoothed data, using the same four-sample rule with the pixels above and below (one outside the block each way), the column's new values are collected in the stack buffer and written back after the column is complete (0x001D8DA4-0x001D8DAF). A zero width or height skips the corresponding loops, the buffer holds 16 entries, so width and height of at most 16 are supported.
