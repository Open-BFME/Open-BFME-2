name: bitread1
rva: 0x001C50B0
size: 74
ret_site: 0x001C50F9 (also 0x001C50C1)
convention: custom register ABI: EAX = pointer to the raw bit reader (0x0 bits remaining in the current word, 0x4 current word, 0x8 pointer to the next unread byte), result in EAX
args: EAX = bit reader pointer (register only)
returns: one bit
callees: none
tables: none
fields: none

Behaviour:
If bits remain, decrements the remaining count and returns bit (remaining) of the word. Otherwise loads the next four bytes big-endian as the word, sets remaining to 31, and returns the top bit.
