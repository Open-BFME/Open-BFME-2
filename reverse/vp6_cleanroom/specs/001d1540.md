# WmtFastDeInterlace

name: WmtFastDeInterlace
rva: 0x001D1540
size: 200
ret_site: 0x001D1607
convention: cdecl, 5 stack args, caller cleans
args: source (byte pointer) | destination (byte pointer) | width (int) | height (int) | stride (int)
returns: none
callees: none (row copies are inlined rep movs)
tables: 0x00DB8100: eight 16-bit 2s (rounding)
fields: none

## Behaviour

SIMD variant of the vertical 1-2-1 deinterlace at 0x001C7580 with identical results: first row copied, each interior row written as (row above + 2 x row + row below + 2) shifted right by 2 per pixel computed in 16-bit lanes and packed back to bytes, last row copied. Processes 16 pixels per step, the column counter advances by 16 while below the width, so a width that is not a multiple of 16 is rounded up for the interior rows (the copies use the exact width). Source/destination advance by the stride. No MMX state clear is executed (the routine uses only SSE2 registers and plain string moves, so no MMX state is touched).
