Behaviour:
Scales a whole YUV picture. The scaled luma width is the source luma width multiplied by the horizontal ratio and divided by the horizontal scale, rounding up (retail adds the scale minus 1 before the unsigned division at 0x001BA7ED). The scaled luma height is formed the same way from the source luma height and the vertical pair (division at 0x001BA808).
Luma is scaled with Scale2D from the source Y plane into the destination Y buffer at the scaled size. If the scaled width is below the destination Y width, every scaled row is extended to the right: starting one column before the scaled width, the destination width minus the scaled width plus 1 bytes are filled with the byte found two columns before the scaled width. If the scaled height is below the destination Y height, the rows from one before the scaled height through the last destination row are each overwritten with a copy of the row two above the scaled height (destination Y width plus 1 bytes).
The U and V planes are scaled to half the scaled width and height (signed halving) with the same two extension rules: the right extension when the halved width is below the destination UV width (for all destination UV rows, filling to the UV width), and the bottom extension from one row before the halved height while below half the destination Y height, copying the row two above the halved height for UV width bytes.
