name: AllocateQuantizerBuffers (static helper)
rva: 0x001B7860
size: 206
ret_site: 0x001B792D (also 0x001B78EB, 0x001B7919)
convention: custom register ABI: EAX = pointer to QUANTIZER (retail quantizer instance, 0x990 bytes), no stack arguments
args: EAX = quantizer instance pointer (register only, no stack arguments)
returns: int in EAX, 1 on success, 0 on failure
callees: 0x001B6410 duck_free, 0x001B6400 duck_malloc, 0x001B7810 DeleteQuantizerBuffers (ESI ABI)
tables: none
fields: as DeleteQuantizerBuffers

Behaviour:
Begins with an inlined copy of DeleteQuantizerBuffers. Allocates 0xA0 bytes (tag 0) for the Y dequantiser: raw to 0x188, if null the delete sequence is run again inline and 0 returned, else the 32-byte-rounded pointer goes to 0x180. Allocates 0xA0 bytes for the UV dequantiser: raw to 0x18C, if null calls DeleteQuantizerBuffers and returns 0, else rounded pointer to 0x184 and returns 1.
