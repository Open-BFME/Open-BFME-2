rva: 0x001D5DA0

fields: none

## Behaviour

Dequantises one block: for each of the 64 transmission positions, the quantised value and the dequantiser coefficient at that position are sign-extended, multiplied as 32-bit signed integers, and the product is stored into the output block at the raster position that the zig-zag table assigns to that transmission position (position 0 goes to raster 0, position 1 to raster 1, position 2 to raster 8, position 3 to raster 16, and so on through the table). All 64 output entries are written exactly once, nothing else is modified. The retail body is fully unrolled (64 multiply-store pairs, first at 0x001D5DA0, last store before the return at 0x001D618D).
