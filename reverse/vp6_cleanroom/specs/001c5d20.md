convention: cdecl
args: [esp+4] pointer to PB_INSTANCE (retail decoder instance), [esp+8] macroblock row, [esp+0xC] macroblock column, [esp+0x10] frame selector byte (1 last frame, 2 golden), [esp+0x14] pointer to an output type dword

Behaviour:
Macroblock info fields referenced: macroblock info at the start of the instance: 0x4 coefficient buffer, 0x8 macroblock mode, 0xC block modes (6 dwords), 0x24 block motion vectors (6 pairs of signed 16-bit x,y), 0x3C nearest inter vector, 0x40 near inter vector, 0x44 nearest inter index, 0x48 nearest golden vector, 0x4C near golden vector, 0x50 nearest golden index, 0x64 block row pixel offset, 0x68 block column pixel offset, 0x70 reconstruction index, 0x74 current reconstruction stride, 0x78 plane, 0x7C motion vector shift, 0x80 motion vector modulus mask, 0x88 frame reconstruction stride, 0xBC above context pointer, 0xC0 left context pointer, 0xC4 last-DC array pointer, 0xC8 interlaced flag.
base = row times columns plus column. Nearest and next-nearest vectors start at zero, type at 1. First pass over the 12 neighbour offsets: skip neighbours whose prediction mode maps to a different frame than the selector. The first neighbour with a non-zero vector sets nearest to it, type to 2, and stops. The index where the first pass stopped (12 if none) is the nearest index. Second pass from the next offset: same frame check, skip vectors equal to nearest, and the first non-zero one becomes the next-nearest with type 0. The type is written to the output. For selector 1 the nearest inter index, nearest inter vector and near inter vector are stored, otherwise the nearest golden index, nearest golden vector and near golden vector.
