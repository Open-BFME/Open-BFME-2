callees: 0x001B56F0 VP6_CreatePBInstance, 0x001B6890 CreatePostProcInstance, 0x001B7990 VP6_CreateQuantizer, 0x001B9410 VP6_InitFrameDetails, 0x001B56A0 VP6_DeletePBInstance, 0x001B9680 VP6_InitialiseConfiguration

fields: 0x234 scale width, 0x238 scale height, 0x23C output width, 0x240 output height, 0x1B0 frame width, 0x1B4 frame height, 0x298 post-processor pointer, 0x13C quantizer pointer, 0x1A4 processor frequency
        quantizer field 0x38 (cached quality value, see VP6_UpdateQ)

Behaviour:
Creates the decoder instance: calls VP6_CreatePBInstance, stores the result through the output pointer (no null check), then writes the width into fields 0x234, 0x23C and 0x1B0 and the height into 0x238, 0x240 and 0x1B4.
Creates the post-processor from the configuration block at 0x1B0 into field 0x298, creates the quantizer into 0x13C, copies the global CPU frequency into 0x1A4, then calls VP6_InitFrameDetails. If that returns 0, VP6_DeletePBInstance is called with the output pointer and 0 is returned.
On success the quantizer's field 0x38 is set to 0, VP6_InitialiseConfiguration is called, and 1 is returned.
