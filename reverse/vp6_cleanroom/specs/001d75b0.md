args: scratch (unused) | destination (bytes) | reference 1 (bytes) | reference 2 (bytes) | residual (int16 pointer, 64 entries, row pitch 16 bytes) | stride (uint)

## Behaviour

Half-pixel inter reconstruction, 8 rows of 8 pixels. Per row: the eight bytes of each reference are zero-extended to 16-bit lanes (0x001D75D9-0x001D75EC), the two are added lane-wise (wrapping, but no wrap can occur for bytes), the sum is logically shifted right by 1 (truncating average, 0x001D75F5/0x001D75F9), the eight residual words of the row are added lane-wise with 16-bit WRAP-AROUND (0x001D75FD/0x001D7600), and the eight results are packed to bytes with unsigned saturation (0x001D7606) and stored to the destination row (0x001D760F). Because the residual addition wraps before the clamp, a residual large enough to overflow 16 bits is not clamped to 255: for example both reference samples 255 and residual 32767 give the byte 0 (255 + 32767 wraps to -32514, which clamps to 0). References and destination advance by the stride per row, the residual by 16 bytes. No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
