convention: cdecl, 5 stack args, caller cleans
args: int16 scratch block | output (byte pointer) | reference (byte pointer) | residual (int16 pointer, stride 8) | line step (uint)

## Behaviour

Inter reconstruction without SIMD: for each of 8 rows and 8 columns, scratch = reference byte + residual (int16), reference rows advance by the line step, residual/scratch rows by 8 entries, then SatUnsigned8(output, scratch, line step, 8).
