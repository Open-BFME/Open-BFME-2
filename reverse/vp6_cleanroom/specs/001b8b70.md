Behaviour:
Bilinear-only byte-output counterpart of FilterBlock_C. With d as defined there: d of 1 gives an inlined horizontal two-tap (bilinear pair for the horizontal phase, 8 rows of 8 bytes), d equal to pixels per line gives the inlined vertical two-tap with the vertical phase, d equal to pixels per line minus 1 calls FilterBlock2dBil_8 with base pointer 1 minus 1, d equal to pixels per line plus 1 calls it with pointer 1, other values write nothing. This routine is installed as the 8-bit block filter pointer (0x00E22D00) by the generic branch of UtilMachineSpecificConfig.
