        0x1A8 CPU-free percentage, 0x294 pointer to the IDCT dispatch table, 0x3A0 DC probability array (22 bytes), 0x3B6 AC probability array (396 bytes)

Behaviour:
Allocates 0x4954 bytes with tag 0. Returns null when the allocation fails. Zero-fills the whole block (0x1255 dwords), then copies the 14-dword configuration template into field 0x1B0 so that horizontal and vertical fragment pixel counts are 8 and everything else is 0.
Calls VP6_AllocateTmpBuffers. If that fails, frees the block and returns null.
Otherwise stores 70 in field 0x1A8, stores the address of the global IDCT function-pointer table (retail VA 0x00E22D40, 65 entries) in field 0x294, zeroes the 22-byte DC probability array at 0x3A0 and the 396-byte AC probability array at 0x3B6, and returns the instance.
