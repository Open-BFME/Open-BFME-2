Behaviour:
Loop filter across a vertical edge, 8 rows (two loop iterations of four rows). F = limit table entry for the Q index. For each row with pixels a, b at offsets minus 2 and minus 1 and c, d at offsets 0 and plus 1: value = (a minus 3 b plus 3 c minus d plus 4) shifted right 3, then bounded by the Bound rule with F (magnitude zeroed when not below 2 F, result F minus the absolute difference of magnitude and F, sign restored). Pixel b gains the bounded value and pixel c loses it through the clamp table. Pointer advances by the pitch per row.
