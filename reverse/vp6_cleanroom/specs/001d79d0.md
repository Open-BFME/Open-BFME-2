# FilterBlock1d_vb8_wmt

name: FilterBlock1d_vb8_wmt
rva: 0x001D79D0
size: 100
ret_site: 0x001D7A33
convention: cdecl, 7 stack args, caller cleans
args: source pointer (bytes) | output pointer (bytes) | source pixels per line (uint) | pixel step (uint, unused in retail) | output height (uint) | output width (uint, used as the output row pitch) | filter taps pointer (int16)
returns: none
callees: none
tables: 0x00DB84D0 eight 16-bit 64 (rounding)
fields: none

## Behaviour

SSE2 version of the two-tap filter with the same contract as 0x001D7080: eight outputs per row, each the sum of a sample weighted by the first eight-entry weight group (taps pointer offset 0) and the sample one row below weighted by the second group (offset 16), plus the rounding constant 64 from the listed table, arithmetically shifted right 7, packed to bytes with unsigned saturation. Rows advance as in the MMX version, 'pixel step' is unused.
