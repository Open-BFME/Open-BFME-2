fields: 0x44 nearest inter index, 0x3C nearest inter vector, 0x50 nearest golden index, 0x48 nearest golden vector, 0x706 is-long probabilities (2 bytes), 0x708 short-magnitude probabilities (2 sets of 7), 0x71C long-magnitude probabilities (2 sets of 8), 0x704 sign probabilities (2 bytes)

Behaviour:
Decodes a motion vector relative to a predictor. The predictor is the nearest inter vector when the mode is 2 and the nearest inter index is below 2, the nearest golden vector when the mode is not 2 and the nearest golden index is below 2, and zero otherwise (0x001C5B16..0x001C5B4E).
Each component (x first, then y) uses its own set of probabilities. A symbol with the component's is-long probability selects a short magnitude (0..7) when clear or a long magnitude when set (0x001C5B54..0x001C5B68).
Short magnitude: a three-level binary tree over seven probabilities. The first decides whether the magnitude is in 0..3 (clear) or 4..7 (set). In 0..3 the second decides 0..1 against 2..3, then the third (for 0..1) or the fourth (for 2..3) supplies the lowest bit. In 4..7 the fifth decides 4..5 against 6..7, then the sixth (for 4..5) or the seventh (for 6..7) supplies the lowest bit (0x001C5B6E..0x001C5C20).
Long magnitude: eight probabilities, one per bit. Bits 0, 1, 2, 7, 6, 5 and 4 are decoded in that order with their own probabilities (0x001C5C25..0x001C5CA8). Bit 3 is decoded with its probability only when at least one of bits 4..7 is set, otherwise bit 3 is forced to 1 (0x001C5CAD..0x001C5CC9).
A non-zero magnitude is negated when a symbol with the component's sign probability is set (0x001C5CD0..0x001C5CE6). The component plus the predictor component is stored into the output vector.
