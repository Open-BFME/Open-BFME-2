# FilterBlock_mmx

name: FilterBlock_mmx
rva: 0x001D7330
size: 486
ret_site: 0x001D7515
convention: cdecl, 7 stack args, caller cleans (0x100-byte local buffer | at 0x001D733A the arguments are at esp+0x104 .. esp+0x11C)
args: reference pointer A (bytes) | reference pointer B (bytes) | output (int16 pointer, 64 entries, row pitch 16 bytes) | pixels per line (uint) | horizontal phase (int, 0..7) | vertical phase (int, 0..7) | bicubic selector (int, zero = bilinear)
returns: none
callees: 0x001D6C90 (4-tap horizontal) | 0x001D6D70 (4-tap vertical) | 0x001D6FF0 (2-tap horizontal) | 0x001D7080 (2-tap vertical) | 0x001D72D0 (4-tap 2-D) | 0x001D7100 (2-tap 2-D) | 0x001D7740 (byte block to int16 widening)
tables: 0x00DB81B0 bilinear filter bank, 8 phases x 32 bytes (each phase: eight copies of a first 16-bit weight, eight copies of a second | the pairs are 128/0, 112/16, 96/32, 80/48, 64/64, 48/80, 32/96, 16/112) | 0x00DB82B0 bicubic filter bank, 8 phases x 64 bytes (each phase: four 16-bit weights replicated eight times | the weight quadruples are 0/128/0/0, -4/118/16/-2, -7/106/34/-5, -8/90/53/-7, -8/72/72/-8, -7/53/90/-8, -5/34/106/-7, -2/16/118/-4) | nothing else is indexed - there is no second-level selector
fields: none

## Behaviour

Builds an 8x8 sub-pixel prediction block from two reference pointers that the caller guarantees differ by 0, 1, one line, one line minus 1 or one line plus 1 (the caller is 0x001C5E30's block predictor through the function pointer slot 0x00E22D1C).

1. The difference B minus A is formed, if negative the two pointers are exchanged and the difference negated (0x001D7340-0x001D7348), so that A is the lower address and the difference is non-negative.
2. If the difference is zero the function returns immediately without writing anything (0x001D734C to 0x001D750F).
3. Otherwise one of six filters fills a 256-byte stack buffer with an 8x8 byte block (row pitch 8). The phase arguments select the filter weights: for the bicubic bank the horizontal or vertical phase times 64 is added to 0x00DB82B0 (0x001D7362-0x001D736C and the corresponding sites), for the bilinear bank the phase times 32 is added to 0x00DB81B0. The bicubic bank is used when the selector argument is non-zero, the bilinear bank otherwise:
   - difference 1: horizontal filter of A (0x001D6C90 or 0x001D6FF0) with arguments (A, buffer, pixels per line, 1, 8, 8, weights for the horizontal phase),
   - difference equal to pixels per line: vertical filter of A (0x001D6D70 or 0x001D7080) with (A, buffer, pixels per line, pixels per line, 8, 8, weights for the vertical phase),
   - difference equal to pixels per line minus 1: 2-D filter (0x001D72D0 or 0x001D7100) of A minus 1 with (A - 1, buffer, pixels per line, horizontal-phase weights, vertical-phase weights),
   - difference equal to pixels per line plus 1: the same 2-D filter of A itself,
   - any other non-zero difference: no filter is called and the buffer keeps whatever the stack held.
4. The buffer is then widened to int16 into the output through 0x001D7740 with (buffer, output, 8) (0x001D74F8-0x001D7507): 64 values of 0..255, eight per 16-byte output row.

No stores other than the output block and the private buffer occur, esi is preserved. No MMX state clear is executed by this routine. On the zero-difference early return (0x001D734C to 0x001D750F) no MMX instruction runs and no MMX helper is called, so the incoming MMX/x87 state is left exactly as it was. On every other path the callees execute MMX instructions and the routine returns with the MMX register state in use (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
