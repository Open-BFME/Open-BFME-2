Behaviour:
Horizontally upsamples 4 input pixels to 5 output pixels per group. For every group while 4 times the group index is below source width minus 4 (the number of full groups is ((source width minus 5) shifted right 2) plus 1, and the loop is skipped entirely when source width is exactly 4): output 0 is input 0 unchanged, then the four blended samples per the 4-to-5 weights: outputs are (51 a plus 205 b plus 128) shifted right 8, (102 b plus 154 c plus 128) shifted right 8, (154 c plus 102 d plus 128) shifted right 8, (205 d plus 51 e plus 128) shifted right 8, where a..e are consecutive input samples. Source advances 4, destination 5 per group.
After the loop one final group is emitted from the remaining inputs where output 4 is a copy of input 3 instead of a blend with a fifth input.
