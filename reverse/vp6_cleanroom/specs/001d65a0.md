# dequant_slow10

name: dequant_slow10
rva: 0x001D65A0
size: 182
ret_site: 0x001D6655
convention: cdecl, 3 stack args, caller cleans
args: dequantiser coefficients (int16 pointer) | quantised values (int16 pointer, transmission order) | output block (int32 pointer, 64, raster order)
returns: none
callees: none
tables: same zig-zag mapping as 0x001D5DA0 (0x00BD8460)
fields: none

## Behaviour

Zero-fills the first 32 int32 entries of the output block (string store of 32 dwords, 0x001D65A8-0x001D65AF), then dequantises the first eleven transmission positions exactly as 0x001D5DA0 does (sign-extended 32-bit products), storing them at raster positions 0, 1, 8, 16, 9, 2, 3, 10, 17, 24 and 32 (the last store, raster 32, at 0x001D664E). Consequently entries 0..31 are either products or zero, entry 32 is the eleventh product, and entries 33..63 are left untouched.
