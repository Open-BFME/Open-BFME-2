name: VP6_ExtractTokenN
rva: 0x001C5200
size: 269
ret_site: 0x001C530C (also 0x001C5286)
convention: custom register ABI: EAX = pointer to the 64-entry lookup table (16-bit entries), EDX = pointer to the raw bit reader (0x0 bits remaining in the current word, 0x4 current word, 0x8 pointer to the next unread byte), EBX = pointer to the Huffman node array (12 bytes per node: left edge dword at 0, right edge dword at 4, probability at 8, an edge's bit 0 set means leaf and bits 1..7 hold the token or child index), result in EAX
args: EAX = lookup table pointer, EDX = bit reader pointer, EBX = node array pointer (registers only)
returns: token value
callees: none
tables: none
fields: none

Behaviour:
Peeks 6 bits (bitreadonly behaviour inlined), looks up the table entry, and consumes the entry's length (bits 12..15, bitShift behaviour inlined). If the entry's bit 0 is set the token is bits 1..5 of the entry. Otherwise bits 1..5 give a starting node and the tree is walked one bit at a time (bitread1 behaviour inlined): a set bit takes the right edge, a clear bit the left edge, until a leaf edge is reached, whose bits 1..7 are returned.
