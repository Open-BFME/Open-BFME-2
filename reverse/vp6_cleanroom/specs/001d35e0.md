# MMX_idct

name: MMX_idct
rva: 0x001D35E0
size: 2374
ret_site: 0x001D3F25
convention: cdecl, 3 stack args, caller cleans | naked routine saving edx/ecx/ebx (0x001D35E0-0x001D35E2)
args: input (int16 pointer, 64 coefficients in transmission (zig-zag) order | 8-byte loads, 2-byte alignment suffices) | quantiser table (int16 pointer, 64 entries in the same transmission order) | output (int16 pointer, 64 entries, natural raster order | used as the working buffer and its cache lines are touched first)
returns: none
callees: none
tables: 0x00E22980 IDCT constant block (48 x uint16), written by the initialiser at 0x001C4300: words 0..15 are zero except words 0, 5, 10 and 15 which are 0xFFFF (lane masks) | words 16..43 hold the seven cosine constants copied from the on-disk table at 0x00DB8188 (64277, 60547, 54491, 46341, 36410, 25080, 12785 = cos(k pi/16) x 65536, k = 1..7), each replicated four times | words 44..47 hold 8 (rounding)
fields: none

## Behaviour

Notation used below: inputs of a 1-D transform are in0..in7, its outputs out0..out7, intermediate terms are named by role, multiplier constants by their retail value (M[c](v) = floor(v x c / 65536), see the multiplier notation paragraph), sat() = clamp to -32768..32767, wrap() = modulo 65536.
Full 8x8 dequantise plus inverse DCT, MMX (four 16-bit lanes). The routine first reads six dwords of the output block (byte offsets 0, 28, 56, 84, 112, 124, 0x001D35EB-0x001D35F9, values discarded). Dequantisation: each of the 64 input lanes is multiplied by the quantiser lane at the same transmission index, low 16 bits kept (first pair 0x001D3609). The products are scattered into the working buffer in the internal layout: transmission index i has natural raster position given by the zig-zag table at 0x00BD8460, and the internal layout additionally transposes each 4x4 quadrant of the natural block (scatter realised with the lane masks of the constant block and 64-bit shifts, 0x001D3614-0x001D38F0). First pass: natural rows 0..3 (0x001D3918-0x001D3A3B) then rows 4..7, each group followed by a 4x4-block transpose in registers, second pass: natural columns 0..3 (0x001D3C44-0x001D3DB1) then 4..7, written in natural raster order (row r, column c at index 8r + c). Each lane carries one row (first pass) or one column (second pass).

Value contract of one 1-D transform of eight 16-bit inputs in0..in7 (obtained by symbolic evaluation of the retail instruction stream, every intermediate is a 16-bit value, 'sat' means the result is clamped to -32768..32767, 'wrap' means it is reduced modulo 65536, the pairs are evaluated difference-first, i.e. a 'sum' is formed as the difference plus twice the second operand, which is why the sum has two saturation points):
- multiplier notation: M[c](v) is floor(v x c / 65536) for the seven retail constants c = 64277 (word 16 of the block at 0x00E22980, i.e. 0x00E229A0, SSE2 copy at 0x00DB8820), 60547 (0x00E229A8 / 0x00DB8830), 54491 (0x00E229B0 / 0x00DB8840), 46341 (0x00E229B8 / 0x00DB8850), 36410 (0x00E229C0 / 0x00DB8860), 25080 (0x00E229C8 / 0x00DB8870) and 12785 (0x00E229D0 / 0x00DB8880), it is realised as the signed high half of the 16x16 product with, for the five constants above 32767, a wrapping add of v (those constants are stored wrapped), M[46341] applied to a derived value is realised the same way (wrapping add-back) except where noted.
- odd pair sums and differences: oddSum17 = sat(M[64277](in1) + M[12785](in7)), oddDiff17 = sat(M[12785](in1) - M[64277](in7)), oddSum35 = sat(M[54491](in3) + M[36410](in5)), oddDiff35 = sat(M[54491](in5) - M[36410](in3)).
- oddDS = sat(oddSum17 - oddSum35), oddSS = sat(sat(oddSum35 + oddSum35) + oddDS), oddDM = sat(oddDiff17 - oddDiff35), oddSM = sat(sat(oddDiff35 + oddDiff35) + oddDM).
- rotated odd terms: rotS = M[46341](oddDS) and rotM = M[46341](oddDM), both with wrapping add-back.
- even terms: evenSum = sat(sat(in4 + in4) + sat(in0 - in4)), rotEvenSum = M[46341](evenSum) with wrapping add-back, evenDiff = sat(in0 - in4), rotEvenDiff = high half of (evenDiff x 46341) plus evenDiff, where this add-back is saturating in this MMX routine (the only saturating add-back, it is wrapping in the SSE2 routines).
- pair26: pairSum26 = sat(M[25080](in6) + M[60547](in2)), pairDiff26 = sat(M[25080](in2) - M[60547](in6)).
- second stage: eA = sat(rotEvenSum - pairSum26), eB = sat(sat(pairSum26 + pairSum26) + eA), oA = sat(rotM - pairDiff26), oB = sat(sat(pairDiff26 + pairDiff26) + oA), fA = sat(rotEvenDiff - rotS), fB = sat(sat(rotS + rotS) + fA).
- first-pass outputs (stored as 16-bit, no rounding, no shift): out7 = sat(eB - oddSS), out0 = sat(sat(oddSS + oddSS) + out7), out2 = sat(fB - oB), out1 = sat(sat(oB + oB) + out2), out4 = sat(eA - oddSM), out3 = sat(sat(oddSM + oddSM) + out4), out6 = sat(fA - oA), out5 = sat(sat(oA + oA) + out6).
- second-pass outputs: the same four pairs, but 8 is added (saturating) to each pair's difference before the sum is derived from it, and both results are arithmetically shifted right by 4: out7 = sat(sat(eB - oddSS) + 8) shifted, out0 = sat(sat(oddSS + oddSS) + sat(sat(eB - oddSS) + 8)) shifted, likewise out2/out1 from fB and oB, out4/out3 from eA and oddSM, out6/out5 from fA and oA.

Supporting sites in this routine: odd products 0x001D3927-0x001D393B, saturating pair combinations 0x001D3958-0x001D3A38, saturating even-difference add-back 0x001D39EA (first pass) and 0x001D3D16 (second pass), rounding adds 0x001D3D35, 0x001D3D5F, 0x001D3D74, final shifts 0x001D3D3F-0x001D3D86 and 0x001D3EAE-0x001D3F12.

All six MMX and SSE2 routines (full and reduced, where the vector lies in the reduced domain) produce these identical results, the MMX full routine's saturating and the SSE2 full routine's wrapping even-difference add-back cannot be told apart by any input, since the M[46341] add-back of a signed 16-bit value always stays within signed 16 bits.
No MMX state clear is executed by this routine: it leaves the MMX register state in use on return (the separately installed clear-state routine at 0x001D7620 is the caller's cleanup).
