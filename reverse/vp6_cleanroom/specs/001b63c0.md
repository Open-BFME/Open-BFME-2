name: duck_malloc core (EA shim)
rva: 0x001B63C0
size: 62
ret_site: 0x001B63FD (also 0x001B63EB)
convention: cdecl
args: [esp+4] size
returns: block pointer or null
callees: virtual slot 0 of the allocator object (args: size, pointer to a 12-byte zeroed descriptor on the stack), or 0x004307F0 (engine allocate, args: size, 0) when no allocator object is installed
tables: 0x00DFDA54
fields: none

Behaviour:
If the allocator object is installed, builds a three-dword zero descriptor on the stack and calls vtable slot 0 with (size, descriptor address), returning its result. Otherwise calls the engine allocator at 0x004307F0 with (size, 0).
