Behaviour:
Thresholds: version 5 and up uses T1 = 384, T2 = 2304, T3 = 2880, T4 = 5760. Otherwise T1 = 2048, T2 = 30720, T3 = 92160, T4 = 122880. Quality = frame Q index. Block index runs over all fragments in Y, U, V order.
Y plane rule per block with variance V (line length = Y stride): if level exceeds 5 and V exceeds T3: strong filter once, and if any of the left, right, below or above neighbour blocks (where they exist) has variance above T4, strong filter twice more. Else if V exceeds T2: strong once. Else if V exceeds T1: weak once. Else copy the block.
U and V planes (line length halved, block counts halved): below version 5 the quality becomes the block's own fragment Q index. If level exceeds 5 and V exceeds T4: strong three times. Else T2 strong, T1 weak, else copy.
