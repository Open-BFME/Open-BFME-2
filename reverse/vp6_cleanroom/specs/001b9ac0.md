ret_site: 0x001B9BEA
convention: cdecl
args: [esp+4] pointer to POSTPROC_INSTANCE (retail post-processor instance), [esp+8] pointer to a YUV buffer config (9 dwords: Y width 0x0, Y height 0x4, Y stride 0x8, UV width 0xC, UV height 0x10, UV stride 0x14, Y pointer 0x18, U pointer 0x1C, V pointer 0x20), [esp+0xC] destination frame base pointer
returns: void
callees: 0x001B96A0 UpdateUMVBorder
tables: none
fields: 0x78/0x7C/0x80 recon Y/U/V offsets, 0x98 Y stride, 0x9C UV stride

Behaviour:
Copies an external picture into a reconstruction frame: Y height rows of Y width bytes from the config's Y pointer (advancing by the config's Y stride) to destination plus recon Y offset (advancing by the instance Y stride), then UV height rows of UV width bytes for U and for V likewise with the UV strides and recon U and V offsets. Row loops are signed and skipped when the count is not positive. Finally calls UpdateUMVBorder on the destination.
