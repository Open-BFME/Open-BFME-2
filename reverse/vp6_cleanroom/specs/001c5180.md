name: VP6_PredictDC
rva: 0x001C5180
size: 126
ret_site: 0x001C51FD
convention: cdecl
args: [esp+4] macroblock info pointer (0x4 coefficient buffer, 0x8 macroblock mode), [esp+8] block position, [esp+0xC] pointer to the last-DC array (4 words indexed by frame), [esp+0x10] above block context, [esp+0x14] left block context
returns: void
callees: none
tables: 0x00BD8D00 mode-to-frame table
fields: none

Behaviour:
frame = mode-to-frame entry of the macroblock mode. If the left context's frame equals it, the prediction is the left DC. If the above context's frame equals it, the prediction gains the above DC. When both matched the sum is rounded toward zero and halved (add 1 if negative, arithmetic shift right 1). When neither matched the prediction is the last-DC entry for the frame. The block's first coefficient (at coefficient buffer plus 128 times the position) gains the prediction, and the last-DC entry for the frame is set to the resulting coefficient.
