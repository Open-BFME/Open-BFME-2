Behaviour:
Equiprobable symbol decode with the same arithmetic contract as the register form at 0x001BB9C0: the boundary is half of (range plus 1) (0x001C4F8F..0x001C4F92), the symbol is 1 when the window value is at least the boundary scaled into the top byte (0x001C4F97..0x001C4F9C), window and range are reduced accordingly, both are doubled exactly once and unconditionally (0x001C4FA2..0x001C4FA4 for symbol 1, 0x001C4FAD..0x001C4FB0 for symbol 0), so the range left behind lies in 128..256 and is exactly 256 when the selected range was 128 (example: range 255, window 0, count 8, position 0 gives symbol 0 and leaves range 256, window 0, count 7, position 0), and one bit is consumed from the refill count with a byte refill from the buffer when it expires (0x001C4FB4..0x001C4FCA). State is written back and the bit returned. A normalise-until-128 loop must not be substituted for the single doubling.
