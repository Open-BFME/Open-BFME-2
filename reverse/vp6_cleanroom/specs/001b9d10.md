Behaviour:
In-place vertical 4-to-5 interpolation of one band: the band's rows 0 to 5 (at multiples of the pitch) hold four source rows (0, 1, 2, 3) already copied into rows 0, 1, 2, 3 and the next band's first source row in row 5, and the routine rewrites rows 1 to 4 so that five output rows are spread over the four inputs. Per column, using the original (pre-update) values of each row: row 1 becomes 51 times row 0 plus 205 times row 1, row 2 becomes 102 times row 1 plus 154 times row 2, row 3 becomes 154 times row 2 plus 102 times row 3, row 4 becomes 205 times row 3 plus 51 times row 5. Each weighted sum has 128 added and is shifted right 8 before being stored as a byte. Row 0 is unchanged. Nothing happens when the width is 0.
