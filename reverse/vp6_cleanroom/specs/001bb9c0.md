name: VP6_DecodeBool128 (register form)
rva: 0x001BB9C0
size: 81
ret_site: 0x001BBA0C
convention: custom register ABI: ECX = pointer to the bool coder state (0x0 low value, 0x4 range, 0x8 value window, 0xC count, 0x10 byte position, 0x14 buffer pointer), no stack arguments, result in EAX, EBX/EBP/ESI/EDI preserved
args: ECX only
returns: decoded bit (0 or 1)
callees: none
tables: none
fields: bool coder 0x4 range, 0x8 value window, 0xC count, 0x10 byte position, 0x14 buffer

Behaviour:
Decodes one equiprobable binary symbol from the arithmetic-coded stream and renormalises by exactly one bit. The decoder keeps a range (an integer from 128 to 256 between calls, see below) and a 32-bit value window whose top byte is compared against the range. The symbol boundary is the range plus 1, halved (0x001BB9CD..0x001BB9D0). The symbol is 1 when the window's value is at least the boundary placed in the window's top byte (shift by 24 at 0x001BB9D4, compare at 0x001BB9D7), in that case both the window and the range lose that boundary amount, otherwise the range becomes the boundary itself. The range and window are then each doubled exactly once, unconditionally (0x001BB9E2 for the window, 0x001BB9E5 for the range), even when the selected range was already 128, so the range after this call lies in 128..256 and may be exactly 256. Example: range 255, window 0, count 8, position 0 gives symbol 0 and leaves range 256, window 0, count 7, position 0. Implementations must keep this single doubling and must not substitute a normalise-until-128 loop, which would consume a different number of bits. One bit of the window has thereby been consumed: the count of bits remaining before the next refill is decremented and, when it reaches 0, the next unread byte of the buffer (at the byte position, which then advances by 1) is merged into the low byte of the window and the count is reset to 8 (0x001BB9EA..0x001BB9FC). Range, window, count and position are written back. The caller must have initialised the state with VP6_StartDecode. The generic reader VP6_DecodeBool accepts the range 256 that this routine can leave.
