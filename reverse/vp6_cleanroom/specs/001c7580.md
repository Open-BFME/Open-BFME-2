# CFastDeInterlace

name: CFastDeInterlace
rva: 0x001C7580
size: 183
ret_site: 0x001C7636
convention: cdecl, 5 stack args, caller cleans
args: source (byte pointer) | destination (byte pointer) | width (int) | height (int) | stride (int)
returns: none
callees: none (memcpy is inlined as rep movs)
tables: none
fields: none

## Behaviour

Generic vertical 1-2-1 deinterlace. The first source row is copied to the first destination row (width bytes). For every interior row r = 1 .. height-2, each destination byte is (above + 2 x current + below + 2) shifted right by 2, where above/below are the same column in rows r-1 and r+1 of the source. Finally the last row (row height-1) is copied. Source and destination advance by the stride. If height is 2 or less, only the first row copy and the final row copy happen (the final copy then targets row 1 regardless).
