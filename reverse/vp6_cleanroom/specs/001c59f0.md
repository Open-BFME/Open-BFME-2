fields: 0x77C same-mode probabilities (10 bytes per type, read at 0x001C5A08), 0x7A4 mode-tree probabilities (9 bytes per (type, previous mode) pair, pair index = type times 10 plus previous mode, base computed at 0x001C5A31)

Behaviour:
First a bool with the same-mode probability for the type and previous mode: when set the previous mode is returned. Otherwise the nine tree probabilities of that pair drive a binary tree of modes, in which each bool reads the tree entry named here by its index:
 entry 0 chooses between the last-frame group (clear) and the other group (set).
 Last-frame group: entry 1 clear leads to entry 3, which gives mode 0 (no vector) when clear or mode 2 (coded vector) when set. Entry 1 set leads to entry 4, which gives mode 3 (nearest vector) when clear or mode 4 (near vector) when set.
 Other group: entry 2 clear leads to entry 5, giving mode 1 (intra) when clear or mode 7 (four vectors) when set. Entry 2 set leads to entry 6: when clear, entry 7 gives mode 5 (golden, no vector) or mode 6 (golden with vector). When set, entry 8 gives mode 8 (golden nearest) or mode 9 (golden near).
