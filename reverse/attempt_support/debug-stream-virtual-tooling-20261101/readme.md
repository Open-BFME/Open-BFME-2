## Behavior

overloads returning their class by reference: bool, __int64 and unsigned __int64.

its siblings, references/pointers, const members and nested declarations.

return types are refused. The normal native installation/class proof, shared-body
refusal, protected names, tombstones, frozen keys, consumer scan, byte verification
and transaction rollback remain mandatory. No generic overload-set guard is removed.
