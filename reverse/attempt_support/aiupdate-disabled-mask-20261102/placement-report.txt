Placement judgement
-------------------

A primary template definition before the header is not itself a specialization-after-instantiation error; a forward-declared primary may also be defined later. The current15 generic definitions all use int template parameters, matching the canonical forward declaration. Do not remove or repurpose the primary: their other N specializations include 7-word kind masks.
A shared specialization must expose the actual11-client API below. A constructor-only4B shell is insufficient. It must remain a4-byte, four-aligned nonpolymorphic value with appropriate constructor/copy/destructor properties; native body equality remains necessary. No conditional fallback to a different BitFlags11 definition is a substitute for one consistent type.
This only bounds canonical AIUpdate clients. Other project TUs still instantiate private/global BitFlags<11> representations without this header. A new specialization must not be presented as globally ODR-complete recovery until that broader type ownership is reconciled;182 consumers alone are not all BitFlags11 users.
