Open-BFME-2 GameSpy Chat SDK provenance (chat/)
===============================================

The record that governs this directory — the owner's permission statement,
the licence findings, the dating of game.dat's SDK snapshot and the list of
deltas against the carrier — is ../PROVENANCE.txt. Until 2026-10-08 this file
was a verbatim copy of that record's BFME 1 original; it now says only what
is specific to chat/.

What is here
------------
Reconstructions, not vendored text. The Area 51 carrier that supplies the
qr2/gp/ghttp/serverbrowsing/gstats modules ships no chat/ directory, so no
period chat text exists to vendor. The seven .c files here are bodies
transcribed from the 2007 public SDK (nitrocaster/GameSpy, src/GameSpy/Chat/)
with the eight local headers (chat.h, chatASCII.h, chatCallbacks.h,
chatChannel.h, chatCrypt.h, chatHandlers.h, chatMain.h, chatSocket.h) standing
in for the period headers, whose 2007 versions drag in the common/gsPlatform
layer that did not exist in the snapshot EA built. The three .cpp files are
this repository's own code (address-named helpers and ChatSdkBodies.cpp), not
SDK sources. CHAT-SDK-LICENSE.txt is the 2014 republisher's BSD-3-Clause file
that circulates with the 2007 SDK, kept as the carrier's text; it is not the
grant (see ../PROVENANCE.txt, "Why no grant is readable from the tree
itself", item 5).

The first BFME 2 chat source was chatCrypt.c, a clean C reconstruction carried
by the Open-BFME-1 reference commit: gs_prepare_key / gs_crypt / gs_xcode_buf
at 0x006A9ED0 / 0x006AA030 / 0x006AA100 (341 / 203 / 52 bytes), independently
compiled and byte-verified against game.dat. The rest followed the same way,
most of it re-placed from Open-BFME-1's reconstructions (the ledger notes name
the BFME 1 donor where one was used).

Ledger (measured 2026-10-08, re-derive rather than quote):

    223 rows   39,894 bytes   all matched, no `vendored=` tag
    re-derive:  grep -c 'GameNetwork/GameSpy/chat/' reverse/functions.csv

Version
-------
Chat >= 1.11.19 (the SDK-side nickname-check table at 0x008E60A0,
10-15-2004) and >= 1.11.17 (`CRYPT des %d %s` at 0x008E6334, 09-15-2004);
no upper bound from strings. That the 2007 text reproduces these bytes says
the functions did not change between late 2004 and 2007; it does not date
them. The 2007 text is the donor, not the version retail linked.

Build flags
-----------
As ../PROVENANCE.txt: `/MD /DNDEBUG`, `__cdecl`, Win32 headers from
reference/shims/gamespy, each TU's `// cl:` line adding the pinned BFME 1
reference tree's GameSpy include directory.
